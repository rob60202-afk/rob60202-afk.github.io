# 椅子搶購小幫手（sihoo.tw）

開賣前自動打開頁面暖機 → 準時刷新 → 選規格 → 加入購物車 → 進到結帳頁 → **嗶一聲停下來，由你本人確認並付款**。

> 刻意不做自動付款：信用卡 3D 驗證本來就要人來按，而且自動送單一旦選錯規格就退不掉。這支程式幫你搶的是「前面那 10 秒」。

## 一、安裝（在自己的電腦上，只需做一次）

1. 安裝 [Node.js](https://nodejs.org/)（LTS 版本）
2. 在這個資料夾打開終端機：
   ```bash
   npm install
   cp config.example.json config.json     # Windows：copy config.example.json config.json
   ```

## 二、設定 `config.json`

| 欄位 | 說明 |
|---|---|
| `productUrl` | **椅子的商品頁網址**（不是活動頁 /page/1111，要點進商品後的那個網址） |
| `saleStart` | 開賣時間，台灣時間格式 `2026-11-11T00:00:00+08:00`；如果現在已經開賣，留空字串 `""` 就會立刻執行 |
| `variantOptions` | 要依序點選的規格文字，例如 `["黑色", "含腳踏"]`，需跟網頁上的字一樣 |
| `refreshIntervalMs` | 刷新間隔，最低 1500ms（刷太快會被網站擋掉，反而搶不到） |
| `cartUrl` | 購物車網址，用來在「加入購物車」後直接跳過去 |
| `selectors` | 按鈕文字，可以填多個；要用 CSS 選擇器就在前面加上 `css=` |
| `chromeChannel` | 想改用電腦上已安裝的 Chrome 就填 `"chrome"` |

## 三、使用流程

```bash
npm run login    # 1. 先登入會員，並在會員中心先存好收件地址、發票資料
npm run check    # 2. 檢查按鈕/規格抓不抓得到（✔/✘），有 ✘ 的話就改 selectors
npm start        # 3. 開賣前 5 分鐘以上執行，接著讓它自己跑
```

看到「★ 已停在結帳流程」並聽到嗶聲後，馬上到瀏覽器確認**品項、規格、數量、金額、折扣**，然後付款。

## 四、開賣前檢查清單

- [ ] 提前 1 天跑過 `check`，確認全部打勾
- [ ] 會員已登入，收件地址、付款方式已預先設定好
- [ ] 電腦關閉睡眠模式，網路使用有線網路
- [ ] 手機同時打開 App 或網頁當作備案（兩邊一起搶）
- [ ] 若網站要求驗證碼（CAPTCHA），請自己手動輸入，程式會繼續等待

## 注意

- 僅供個人購買一張椅子使用。請不要開多個帳號，也不要把刷新間隔調得更低，以免違反網站使用條款或被封鎖。
- `profile/`（登入狀態）與 `config.json` 已列入 `.gitignore`，不會上傳到 GitHub。
