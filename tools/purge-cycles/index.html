吹淨次數試算

錶歸零,管子不是空的。輸入錶上的讀數和要達到的濃度,算出理想情況下最少要做幾次,以及每做一次還剩多少。

先看這幾條:
  • 算出來的是理想情況下的最少次數,偏樂觀。盲管、長支管、同一頭進出,實際會比算的差;合不合格,看量測。
  • 要多乾淨、做幾次、怎麼做,依業主的程序書。覺得程序不夠,提出來,不要自己改。
  • 不適用毒性、可燃、自燃、腐蝕等危害性氣體,這些要依專門程序。也不適用水氣(水氣會黏在管壁上,比算的慢)。
  • 充壓不可以超過這條管線允許的壓力;抽真空要確認每個元件都吃得了真空,並經業主同意。排氣接到業主指定的排放口。
壓力 錶壓。例:片中打到 4。
錶壓。放到零就填 0。 一般填 1.013。片中為了好算用 1。
濃度 不確定就當整條都是空氣:含氧約 21% = 210,000 ppm。 依業主的程序書。沒有程序書,先問清楚再算。 吹淨氣本身的雜質,不可能洗得比它更乾淨。

每做一次,還剩多少

算法:每做一次,剩下的比例 = 洩壓後的絕對壓力 ÷ 充壓後的絕對壓力。絕對壓力 = 錶壓 + 大氣壓。做 n 次以後,剩下的 = 吹淨氣的濃度 + (一開始 − 吹淨氣)× 比例的 n 次方。假設每次都混得很均勻、沒有漏、溫度不變。

本工具是理想情況下的估算,不是規範,也不保證合格。實際的目標、次數與程序,依業主的程序書或氣體供應商的程序;合不合格,以量測為準。填寫內容只存在你這台裝置的瀏覽器裡,不會上傳。
