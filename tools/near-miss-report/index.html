虛驚事件回報範本

差一點的事,講出來,才不會變成真的。填好下面幾段,就是可以直接傳給工安或主管的回報。

寫虛驚回報的原則:
  1. 只寫事實,不寫誰的錯。目的是找原因,不是找人。
  2. 寫清楚差點造成什麼後果,大家才知道有多危險。
  3. 建議改善要寫具體做法,不要只寫「加強注意」。
  4. 當天寫,當天傳。

小提醒
  • 虛驚不是沒事,是還沒出事。
