# 工安檢核表審查紀錄

審查對象:每日開工安全確認表、侷限空間作業前確認表、閥位復歸確認表、完工自主檢查表,以及上鎖掛牌確認表。
審查方式:由一位扮演「職業安全衛生管理師兼品管主管」的 AI 審查員獨立審查,再由 Claude 修改。這不是專業人員的簽核,發佈前仍請 Rob 與有經驗的工安人員看過。

## 已修改的重點

| 等級 | 表 | 修改 |
|---|---|---|
| 高 | 侷限空間 | 救援寫明要戴空氣呼吸器或輸氣管面罩;防毒面具、口罩在缺氧時沒用;送新鮮空氣,不可以送氧氣 |
| 高 | 侷限空間 | 作業中持續通風;休息後再進去要重測;測定從外面用採樣管測上、中、下 |
| 高 | 侷限空間 | 「六、結束」改成出來後再填;「不適用」只用在空間真的沒有那樣東西 |
| 高 | 每日開工 | 侷限空間那一條原本是問句,按「有/無」邏輯相反,改成肯定句,沒有就選「不適用」 |
| 高 | 每日開工 | 「十、收工」改成收工時再填,不擋開工判斷 |
| 高 | 閥位復歸 | 「關了要掛牌」改成「動了就掛牌」:為了洩壓而打開的排放閥、排氣閥、旁通閥也要掛牌、記錄 |
| 高 | 閥位復歸 | 「操作前」有一項是「無」就不動閥 |
| 高 | 全部 | 「已回報負責人處理」改成「已回報負責人,處理好之前不做/不進去/不動手」 |
| 中 | 每日開工 | 安全帽下巴帶、掛點全程扣著、合梯、採光罩與浪板踏穿、移動式施工架不推人、動火後留人看悶燒、第一次開接頭當作有壓 |
| 中 | 侷限空間 | 閥會內漏,優先盲板;清污泥會冒出硫化氫;設備試過啟動不了;裡面動火或用溶劑另外評估;警報或不舒服立刻全部出來 |
| 中 | 閥位復歸 | 開閥前確認沒人在管線上作業、慢慢開、有人看著接頭;交班逐顆交接 |
| 中 | 完工自主檢查 | 測試分成測試前與測試後;加壓時拉警戒、不站正前方;有壓力不修;接點追管確認;吹淨出口固定與氮氣窒息 |

網頁上,「之後再填」的段落會標出黃色標籤(例如「收工時再填」),前面幾段填完就會顯示可以開工或可以進去的訊息。

## 待 Rob 向業主或專業人員確認

1. **「誰關的誰開」**:不少科技廠規定運轉中系統的閥只能由廠務或使用單位操作,承商不能自己開回去。人不在的時候,別人的鎖怎麼解,也要有程序。表上已加「運轉中系統的閥由誰操作,依廠規」,請確認常配合的業主怎麼規定。
2. **侷限空間要不要加「作業主管在現場指揮」**:缺氧危險作業依規定要指定作業主管,一般侷限空間各廠要求不同。確認後再決定要不要加。
3. **充氮或不能通風的空間**:「持續通風」做不到,要另外的程序與供氣式呼吸器。表上已寫「不能通風的空間另依廠規,本表不適用」,請確認這樣寫是否足夠。
4. **用氣體做壓力測試**:能不能用、警戒範圍多大、要誰核准,完全看業主規範。完工自主檢查表的寫法請跟常配合的業主對過。
5. **這幾張表和業主作業許可單的關係**:侷限空間、閥位、上鎖掛牌三張已加「本表是自我確認,不能取代作業許可」,請確認不會跟業主文件衝突。
