## 使用規則

1. **發佈前必須由具備實務經驗的人審稿。** 題庫與腳本由 AI 參考網路資料撰寫,撰寫時多數原廠技術文件與法規原文無法直接開啟,數字與程序可能有誤。
2. 標有「待確認」的內容,在確認前不得寫成既定事實。
3. 工安與法規類內容,製作前要核對現行條文。
4. 不使用任何真實公司、業主、人名、單價。
