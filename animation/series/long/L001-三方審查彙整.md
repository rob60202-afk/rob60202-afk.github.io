# L001〈卡套接頭為什麼會漏〉三方審查彙整

三個審查角色各自獨立閱讀腳本、彼此看不到對方意見:

- **應用**:雙卡套接頭技術應用工程師(負責查證原廠文件)
- **領班**:資深配管領班
- **品保**:品保稽核兼教材編審

三者背後是同一個 AI 模型,意見一致不代表正確。

## 一、已讀到原文的原廠文件

審查當時原廠網站被網路設定擋住,三個角色都只看到搜尋摘要。之後網路設定開放,PM 已下載並讀完一份原廠安裝說明全文:

**Swagelok Tube Fitting Instructions for 1 in. (25 mm) and smaller fittings,文件編號 MS-12-01,2021 年 3 月 RevF**
來源:https://www.swagelok.com/downloads/webcatalogs/en/MS-12-01.PDF

該文件原文確認的內容(僅代表這一家原廠、這一個產品系列):

| 項目 | 原文內容 |
|---|---|
| 適用範圍 | 1 吋(25 mm)以下的接頭 |
| 第一步 | 管子完全插入並頂到肩部,螺帽用手轉緊 |
| 高壓與高安全係數系統 | 再把螺帽鎖到管子無法用手轉動、也無法軸向移動,才開始算圈數 |
| 記號 | 在螺帽的六點鐘位置做記號 |
| 圈數 | 固定本體,螺帽轉一又四分之一圈到九點鐘位置 |
| 小尺寸 | 1/16、1/8、3/16 吋與 2、3、4 mm:四分之三圈到三點鐘位置 |
| 間隙規 | 首次安裝時使用;塞不進去代表鎖得夠,塞得進去代表需要再鎖 |
| 重複組裝 | 可拆裝多次;拆之前在螺帽後方的管子上做記號,並沿螺帽與本體的六角面畫一條線;裝回時把帶卡套的管子插到前卡套頂住本體,用扳手轉回原記號位置,會感到阻力明顯增加,再稍微帶緊 |
| 警告 | 拆卸前一定要先洩壓 |
| 注意 | 重複組裝的接頭不可使用間隙規;不可與其他廠牌的零件混用或互換 |
| 較大尺寸 | 5/8 吋到 1 吋(鋁與黃銅除外)建議用液壓預裝工具先預裝卡套 |

該文件**沒有**提到的內容(仍屬未查證):帶壓不可鎖緊、不可用鬆螺帽方式洩壓、切管與去毛邊的做法、間隙規塞得進去時每次補鎖多少、已受壓過的接頭能否直接補鎖、管材硬度與壁厚、管塞等例外件的圈數、其他廠牌的圈數。

## 二、兩方以上都指出的問題(必須修改)

| # | 問題 | 誰指出 | 改法 |
|---|---|---|---|
| 1 | **結尾用間隙規放行了它驗不出來的缺陷**。第一章說有幾顆沒確認插到底、整把管子是拖進來的,結尾卻只重做一顆,其餘三十九顆過間隙規就收工。間隙規只量螺帽與本體的間距,驗不出沒插到底、毛邊、刮痕。這抵觸第六章自己的「沒漏跟做對是兩件事」 | 三方 | 間隙規的限制加一條「量不出管子有沒有插到底」。結尾改成:只有確定看過有插到底的才用間隙規驗收;沒把握的洩壓後拆開檢查卡套咬的位置,位置不對就切掉重做;阿樹更晚下班 |
| 2 | **洩壓只演開洩壓閥、看錶歸零**。沒有先關上游閥並掛牌;沒提不可用鬆螺帽的方式洩壓;沒提氮氣排放的位置 | 三方 | 改成:先關來源閥、掛牌,從洩壓閥排到安全處,確認這一段的錶歸零;不靠鬆螺帽放氣 |
| 3 | **「螺紋完全不負責密封」「不用纏止洩帶」沒限定哪一端**。接頭另一端若是錐度管牙,正是靠螺紋加止洩材密封 | 三方 | 限定為卡套這一端;另一端若是管牙照樣要纏 |
| 4 | **一又四分之一圈被教成通則**。只適用標準接頭的首次組裝;管塞、轉接短管、預裝過卡套的管端、其他系列圈數不同 | 應用、品保 | 加註適用範圍,例外情況不寫數字,一律指向原廠說明 |
| 5 | **第四章的「螺帽後緣畫線」驗不出有沒有插到底**,且找不到原廠把它列為首次組裝步驟;全片三種記號混在一起 | 三方 | 改成插入前先量好深度做記號,並明講是師傅自己的檢查習慣;三種記號各取一個固定名稱 |
| 6 | **氣壓測試與測漏的安全交代不足**。在未驗證的接頭上直接加壓;人貼著帶壓接頭噴測漏液 | 三方 | 加壓前先全數檢查;先低壓查一輪再分段升壓;人站在接頭側邊 |
| 7 | **「三個老毛病」與故事對不上**。故事裡最多的錯是圈數不夠,卻不在清單裡;阿樹實際上不只中兩個 | 領班、品保 | 改成四個,加入圈數憑感覺;不宣稱排名 |
| 8 | **第七章重做的處置沒交代**。切短後管子不夠長會被硬拉;本體沿用卻沒檢查斜面;切管的屑沒清 | 三方 | 補上:本體斜面檢查、管子短了就整段重配不硬拉、清屑 |
| 9 | **不安全或不可能的畫面**。在施工區喝茶;拖管子火花四濺;現場接手機;安全帽與無塵室場景矛盾;沒指定扳手種類;只規定阿樹的防護具 | 領班、品保 | 泡茶移到休息區;火花改成刮痕特寫;服裝依場景統一;扳手畫合尺寸的開口扳手;所有角色都有防護具 |
| 10 | **場景設定不合理**。氮氣支管上四十顆卡套、無塵室的管架、氣體配管工程師 | 領班、品保 | 見第四節 A |
| 11 | **「散了就不要用」過度保守**,也沒教怎麼認方向 | 應用、領班 | 改成:新品不用拆,管子直接插;散了就照圖把方向裝對,不確定或沾髒的才不要用 |

## 五、三方都認為寫得對、不要改的地方

- 「手放下。管子裡還有壓力,你要拿扳手去動它?」以及「漏了就補鎖,那是在賭」
- 「不靠手感,靠圈數」;雙扳手、固定本體
- 前卡套負責密封、後卡套負責抓牢的分工
- 「沒漏跟做對是兩件事」;重複組裝不能再轉一又四分之一圈
- 圈數後面立刻接「以原廠安裝說明為準」;不寫可重組次數;壓力錶不畫數值
