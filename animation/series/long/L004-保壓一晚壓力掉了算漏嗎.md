# L004 保壓一晚,壓力掉了算漏嗎?

- **類型**:故事 + 計算拆解(長片,橫式 16:9,Q 版卡通)
- **主標題**:保壓一晚,壓力掉了算漏嗎?師傅只問了一句:昨晚冷不冷
- **備選標題(測試用)**
  1. 早上壓力少了 0.17 bar,菜鳥抓起扳手——師傅說:手放下
  2. 保壓測試的溫度修正:為什麼一定要用絕對壓力和絕對溫度
  3. 錶看不出來,不等於沒漏:保壓測試能說明什麼、不能證明什麼
- **給觀眾的一句承諾**:看完這支影片,你會用絕對壓力和絕對溫度,算出一晚的壓降有多少是冷出來的,也知道這個算法能說明什麼、不能證明什麼。
- **目標觀眾**:剛進現場、要寫保壓紀錄的配管新人與技術員;帶新人的領班;要看懂保壓紀錄的品管、監工與廠務工程師;對工程現場好奇的理工科學生。
- **預估長度**:約 10 分鐘(旁白與台詞 2,722 個中文字,以程式計數,不含標點、數字與英文單位;各章語速見製作備註)
- **固定角色**:阿樹(氣體配管承攬商工班的菜鳥,認真、容易臉紅)、陳師傅(同一家公司的資深領班,冷靜、冷面笑匠、用問題教人)。配角:業主的品管(不取名)。
- **場景**:虛構晶圓廠的下層(二次配施工區)。阿樹的工班新配好 A、B 兩條管線,沿著外牆邊的管架走,依業主的程序書各做一晚的保壓測試。
- **服裝**:施工區所有角色(含背景人物與品管)一律安全帽、護目鏡、手套、安全鞋,不穿無塵衣(沿用 L001 的設定)。本集白板也放在施工區,所以白板場景照樣全套防護具。
- **聲明**:故事、工廠、人物與數字皆為虛構。片中的測試壓力、溫度、時間都是為了好算而取的整數,**不是測試規範**。測試介質、測試壓力、穩定時間、保壓時間、儀錶要求與允收標準,一律依業主的程序書或適用的規範,不是本片說了算。

## 第二章 兩個假的零(1:21–2:55)【教學】

| 旁白或台詞 | 畫面 |
|---|---|
| **陳師傅**:管子封起來了。沒漏的話,裡面的氣跑得出去嗎? | 工具櫃旁的白板(仍在施工區,兩人全套防護具,附近沒有任何飲料)。陳師傅畫一段兩端封住的管子,裡面一群小圓點 |
| **阿樹**:跑不出去,也沒有新的進來。 | 小圓點旁標「一樣多」 |
| **陳師傅**:那壓力是從哪裡來的? | 白板上一個大問號 |
| **旁白**:氣體分子一直在亂跑,一直撞管壁。這些撞擊加起來,就是壓力。溫度高,分子跑得快,撞得用力;溫度低,跑得慢,撞得輕。氣一樣多、管子一樣大,變冷了,壓力就低。 | 左右兩格:左「27°C」分子拖著長速度線,撞壁冒出大星星;右「21°C」速度線短、星星小。兩格下方標「氣一樣多、管子一樣大」 |
| **旁白**:反過來,管子變熱,壓力也會往上跑。所以壓力沒掉,也不代表沒漏。 | 同一段管子變成暖色,錶的數字往上跳;小字「變熱 → 壓力上升,可能把漏蓋掉」 |
| **陳師傅**:從二十七度降到二十一度,少了六度。壓力會不會跟著少六除以二十七,兩成多? | 白板寫「6 ÷ 27 ≈ 22%?」 |
| **阿樹**:不會吧?錶才掉一點點。 | 阿樹指向測試錶:7.00 → 6.83 |
| **陳師傅**:因為攝氏零度,不是沒有熱。零度的時候,分子還在跑。要冷到負二百七十三度,才是真正的零。從那裡算起,叫絕對溫度,單位是 K。 | 溫度計長條圖:0°C 只是中間一格,往下延伸到 −273.15°C,標「真正的零 = 0 K」。白板:**K = °C + 273**(小字:精確值 273.15,本片用 273,影響見附錄) |
| **旁白**:二十七度是三百 K,二十一度是二百九十四 K。從真正的零算起,只少了百分之二。 | 白板:27 + 273 = 300 K;21 + 273 = 294 K;294 ÷ 300 = 0.98 → 少 2%。旁邊的「6 ÷ 27 ≈ 22%」被劃掉,標「從假的零算」 |
| **阿樹**:所以每降一度,壓力大約少三百分之一? | 白板:1 ÷ 300 |
| **陳師傅**:是絕對壓力的三百分之一左右。記住,是絕對的。 | 陳師傅在「絕對」兩個字下面畫兩條線 |
| **陳師傅**:壓力錶也一樣。錶上的零,是真的沒有壓力嗎? | 一支歸零的壓力錶特寫,旁邊一個問號 |
| **阿樹**:不是……外面還有空氣在壓。 | 錶外圍一圈空氣分子往錶上擠 |
| **陳師傅**:錶量的,是比外面的大氣多出多少,叫錶壓。加上大氣壓,大約一 bar,才是絕對壓力。 | 壓力柱:下段「大氣壓 約 1 bar」,上段「錶壓」,整根「絕對壓力」。白板:**絕對壓力 = 錶壓 + 大氣壓(約 1 bar)** |
| **旁白**:兩個零,都不是真的零。算溫度造成的變化,溫度要用絕對溫度,壓力要用絕對壓力。在這種壓力下,把氮氣當成理想氣體算,誤差很小。 | 白板上兩個「0」加上引號,旁寫「假的零」。下方一行大字:**比例,要從真正的零算起**。角落小字「理想氣體近似,本例誤差約 0.003 bar、偏保守;壓力很高或換別種氣體,要另外評估」 |
| **陳師傅**:記住這兩個零。等一下你就知道,它們有多會騙人。 | 陳師傅把白板筆塞到阿樹手上 |

## 重點整理(片尾卡)

**一行公式**

> P₂應有(錶壓)= P₁絕對 × T₂/T₁ − 大氣壓;其中 P₁絕對 = P₁錶壓 + 大氣壓,T = °C + 273;修正後的壓降 = P₂應有 − P₂實際

**使用條件(與公式同一張卡)**

- 同一段封閉的管線:氣源已關斷並拆離,保壓期間沒有加氣、放氣。
- 溫度用**管子**的溫度(代表管內的氣),不是房間的空氣;打壓後等穩定才開始記錄;早晚量同一位置,和壓力同時記;換成 K 再算。
- 壓力全部換成**同一種單位的絕對壓力**再算;大氣壓用當地實際的氣壓。一晚之間天氣變化大時,昨晚加的是昨晚的大氣壓,早上減的是早上的大氣壓;或改用絕對壓力計。
- 理想氣體近似:本片這種中低壓的氮氣誤差很小(本例約 0.003 bar,偏保守);壓力很高或換別種氣體,要另外評估。
- 算出來的只能**解釋**壓降,不能證明沒有小漏;修正後的壓降要和錶的解析度、溫度量測的誤差一起看;合不合格依業主程序書或適用規範的允收標準。

**本集範例**:(7.00 + 1.00)× 294/300 − 1.00 = 6.84 bar;6.84 − 6.83 = 修正後的壓降 0.01 bar,小於本例錶與溫度量測能分辨的範圍。若把錶壓直接乘溫度比:7.00 × 0.98 = 6.86,會多算出 0.02 bar 的「漏」。

**五個重點**

1. 保壓掉了壓力,先別拆也別簽:密閉管線的壓力會跟著溫度走。管內有壓力時,不准動接頭。
2. 比例要從真正的零算起:壓力用絕對壓力(錶壓 + 大氣壓),溫度用絕對溫度(°C + 273)。把錶壓直接乘溫度比,變冷時會誤以為漏,變熱時會把漏蓋掉。
3. 溫度要量管子,不是房間:貼緊管壁、避開風口與熱源、多點量、早晚同一點、和壓力同時記;打壓後等穩定才開始;起點的溫度事後補不回來。本例溫度量差 1°C,修正就差約 0.03 bar。
4. 錶分不出來的變化,不等於沒有變化:分清解析度和精度;允收標準跟錶的一格差不多或更小,這支錶就不能拿來判定;錶沒掉,先確認氣源已拆離。修正只能解釋壓降,不能證明沒有小漏。
5. 修正後的壓降還是很大:先查自己接上去的測試錶與接頭,再分段隔離、縮小範圍,用業主允許的方法找漏;修之前先洩壓、確認歸零、掛牌;修好從頭重測。測試介質、測試壓力、保壓時間與允收標準,一律依業主程序書或適用的規範。
