# L002 這瓶氣還能用幾天?

- **類型**:計算拆解(長片,橫式 16:9,Q 版卡通)
- **主標題**:這瓶氣還能用幾天?菜鳥答不出來的一題,白板十分鐘算給你看
- **備選標題(測試用)**
  1. 業主問「還能用幾天」,他回「應該沒問題」——然後清晨五點電話響了
  2. 鋼瓶壓力錶怎麼換算成「天數」?一個公式、一個最常犯的錯
  3. 為什麼鋼瓶不能用到零?氣瓶剩餘天數的現場算法
- **給觀眾的一句承諾**:看完這支影片,你看著壓力錶就能估出這瓶壓縮氣體大約還能用幾天,也知道哪一種瓶子絕對不能這樣算。
- **目標觀眾**:剛進氣體、廠務、設備領域的新人工程師與技術員;需要回答業主「還能撐多久」的現場人員;想了解鋼瓶供氣基本觀念的理工學生。
- **預估長度**:約 10 分鐘(旁白與台詞約 2,700 個中文字,另有少量數字與英文單位)
- **固定角色**:阿樹(菜鳥氣體工程師,認真、容易臉紅)、陳師傅(資深領班,冷靜、冷面笑匠、用問題教人)。配角:業主的課長(不取名)。
- **聲明**:故事、工廠、人物與數字皆為虛構。片中數字是為了好算而取的整數,計算結果是**估計值**,實際設定請依現場管線需求、供應商規定與公司程序。

## 第三章 鋼瓶上的兩個數字(1:50–3:45)【教學】

| 旁白或台詞 | 畫面 |
|---|---|
| **陳師傅**:我問你,要知道一瓶氣剩多少,要先知道哪兩件事? | 休息室白板。陳師傅畫一支 Q 版鋼瓶,旁邊兩個問號 |
| **阿樹**:壓力,還有,瓶子多大? | 兩個問號變成「壓力 P」與「容積 V」 |
| **陳師傅**:對。瓶子多大,看瓶肩上的鋼印。那個叫水容積,就是整支瓶子裝滿水,能裝幾公升。這支是四十公升。 | 鋼瓶瓶肩放大,鋼印示意:「V 40 L」。動畫:水灌滿瓶子,跳出「40 L」。白板寫:**V = 40 L** |
| **阿樹**:為什麼要用水來講?裡面裝的又不是水。 | 阿樹歪頭,頭上一個水滴問號 |
| **陳師傅**:因為水壓不扁。用水量出來的,就是瓶子裡面真正的空間。不管之後灌什麼氣、灌多少壓力,這個空間都不會變。 | 動畫:一隻手想把水壓扁,壓不動;換成氣體,一壓就縮。瓶內空間用虛線框出來,標「40 L 不會變」 |
| **陳師傅**:第二個,壓力,看錶。但是先看單位。bar、MPa、psi,還有現場講的「公斤」,通通不一樣。一百 bar 等於十 MPa,大約一千四百五十 psi。單位看錯,後面全錯。 | 三個並排的錶面:100 bar/10 MPa/1450 psi,指針位置相同。白板寫:**P = 100 bar(錶壓)** |
| **阿樹**:現場大哥說的「一百五十公斤」,是什麼? | 阿樹回想:一位資深技術員拍著鋼瓶說「這支一百五十公斤啦」 |
| **陳師傅**:公斤每平方公分。一公斤大約零點九八 bar,粗算可以當成一樣,但是寫在報告上,單位要寫清楚。 | 白板小字:1 kgf/cm² ≈ 0.98 bar。陳師傅在「單位」兩個字下面畫兩條線 |
| **阿樹**:可是四十公升的瓶子,怎麼會有幾千公升的氣? | 阿樹比出一個小瓶子,再比出一個很大的範圍,一臉困惑 |
| **陳師傅**:因為它是硬壓進去的。溫度不變的時候,壓力乘體積是固定的,這叫波以耳定律。四十公升、一百 bar 的氣,放出來變成一 bar,體積就變一百倍,大約四千公升。 | 動畫:瓶內擠滿小氣體分子,打開後膨脹成一百個瓶子大小的雲。白板寫:**P₁V₁ = P₂V₂** → 100 × 40 = 1 × 4000 |
| **旁白**:所以對這種壓縮氣體,剩下的量大致跟壓力成正比。錶掉一半,氣就大約剩一半。 | 並排三支瓶:150/75/0 bar,瓶內顏色條等比例下降 |
| **陳師傅**:不過有個前提,溫度要差不多。同一瓶氣,中午熱的時候錶會高一點,清晨冷的時候會低一點,氣並沒有變多變少。大概每差三度,讀數差百分之一。 | 同一支瓶子,左邊太陽、右邊月亮,兩邊壓力錶指針差一點點,瓶內分子數量一樣。小字:「約 3°C ≈ 1%」 |
| **阿樹**:師傅,那錶歸零的時候,瓶子裡是真的空了嗎? | 阿樹舉手,像小學生 |
| **陳師傅**:好問題。錶上的零不是真的零。壓力錶量的是「比大氣高多少」,叫錶壓。錶指零的時候,瓶子裡還有一個大氣壓的氣,只是跟外面一樣大,出不來。錶壓加上大約一 bar,才是絕對壓力。公式裡真正用的是它。 | 圖解:一根壓力柱,下面一段標「大氣壓 約 1 bar」,上面一段標「錶壓」,整根標「絕對壓力」。白板寫:**絕對壓力 = 錶壓 + 約 1 bar** |
| **陳師傅**:還有,這是理想氣體的算法。壓力很高的時候,真實的氣體沒有這麼聽話。像氮氣在兩百 bar 附近,實際的量會跟這樣算的差幾個百分點。所以先記住一件事:我們算出來的,是估計值。 | 小氣體分子在高壓下互相推擠、翻白眼。白板角落貼上一張黃色便利貼:**「估計值!」**(此便利貼之後每一章都留在白板上) |

## 第四章 阿樹的第一次計算(3:45–5:00)【教學 + 典型錯誤】

| 旁白或台詞 | 畫面 |
|---|---|
| **陳師傅**:來,你算。禮拜五下午五點,錶是一百 bar。能用的氣有多少? | 陳師傅把白板讓出來,自己坐下喝茶 |
| **阿樹**:四十乘一百,四千公升! | 阿樹很有自信地寫:40 × 100 = 4000 L,還畫了一個驚嘆號 |
| **陳師傅**:你打算用到幾 bar? | 陳師傅放下茶杯 |
| **阿樹**:用到……零啊? | 阿樹的筆停在半空 |
| **陳師傅**:這就是你禮拜五錯的地方。鋼瓶不能用到零。 | 白板上的「4000 L」被陳師傅畫一個紅色問號 |
| **旁白**:第一,調壓器要有足夠的進口壓力,出口才穩得住。瓶壓掉到接近管線壓力,後面的機台就開始吃不飽。 | 圖解:鋼瓶 → 調壓器 → 管線 → 機台。瓶壓條下降到接近管線壓力線時,機台表情變成餓肚子 |
| **旁白**:第二,瓶子裡要留一點正壓。用到見底,外面的空氣和水氣可能倒灌進去,這支瓶子就被污染了。 | 圖解:瓶內壓力歸零,瓶口外的空氣與水滴小人偷偷往瓶裡鑽。蓋上紅色「污染」章 |
| **陳師傅**:所以每一條線都有一個換瓶壓力。這條線我們訂十 bar。這個數字不是我說了算,要看管線需要的壓力,還有供應商的規定。 | 鋼瓶圖上畫一條紅色虛線,標「換瓶壓力 10 bar」。虛線以下塗灰,標「不能用」 |
| **阿樹**:可是剩下那十 bar 的氣不用,不是很浪費嗎? | 阿樹指著灰色區域,一臉捨不得 |
| **陳師傅**:四十公升乘十 bar,四百公升。跟一整條線停掉比,你覺得哪個貴? | 天平:左邊一小朵「400 L」的雲,右邊一整排停擺的機台,天平重重倒向右邊 |
| **阿樹**:線停掉。 | 阿樹默默把手放下 |
| **陳師傅**:而且那不叫浪費。那是這支瓶子回去以後,還能乾乾淨淨再灌一次的保險。 | 灰色區域的標示從「不能用」多加一行小字「保護瓶子」 |
| **阿樹**:那能用的,是從一百用到十,九十 bar? | 阿樹在鋼瓶圖上標出 100 → 10 的區間,寫「90 bar」 |
| **陳師傅**:對。四十公升乘九十,三千六百公升。 | 白板:~~40 × 100 = 4000~~ 改成 **40 × (100 − 10) = 3600 L** |
| **阿樹**:那剛剛說的絕對壓力,要不要加一? | 阿樹指著上一章的「錶壓 + 約 1 bar」 |
| **陳師傅**:算「總共有多少」的時候要加。但你現在是兩個壓力相減,兩邊都加一,一減就消掉了。所以直接拿錶上的讀數相減就可以。 | 白板小字:(100 + 1) − (10 + 1) = 90,兩個「+1」被劃掉並冒出小煙 |

## 第五章 把流量換成「一天」(5:00–6:50)【教學 + 故事回扣】

| 旁白或台詞 | 畫面 |
|---|---|
| **陳師傅**:氣有了。再來,這條線一天吃多少? | 白板左邊留著「可用 3600 L」,右邊畫一個流量計 |
| **阿樹**:流量計上面寫一 slpm。 | 流量計特寫:1.0 slpm |
| **陳師傅**:什麼意思? | 陳師傅挑眉 |
| **阿樹**:每分鐘,一公升? | 阿樹不太確定 |
| **陳師傅**:每分鐘一「標準」公升,就是換算到標準狀態下的體積,跟我們剛剛算的那種公升大致是同一種,所以可以拿來除。不過標準狀態是訂在零度還是二十度,每台儀器不一樣,會差到百分之七、八。這也是後面一定要留餘裕的原因。 | 字卡:slpm = standard liter per minute。旁邊小字:「標準狀態:0°C?20°C?看儀器規格」。黃色便利貼「估計值!」閃一下 |
| **旁白**:一分鐘一公升。一小時六十分鐘,就是六十公升。一天二十四小時,一千四百四十公升。 | 白板逐行出現:1 L/分 × 60 = 60 L/時 → 60 × 24 = **1440 L/天** |
| **阿樹**:如果機台不是二十四小時都在用呢? | 阿樹舉手。機台圖示上出現一個開關 |
| **陳師傅**:那就照實際的時數算。一天只開十二小時,就是六十乘十二,七百二十公升。不確定的話,用比較大的那個數字。寧可早換,不要晚換。 | 白板旁註:只開 12 小時 → 60 × 12 = 720 L/天。下面一行:「不確定 → 用大的」 |
| **阿樹**:三千六百除以一千四百四十,二點五天! | 白板:3600 ÷ 1440 = **2.5 天** |
| **陳師傅**:二點五天是幾個小時? | 陳師傅指著時鐘 |
| **阿樹**:六十個小時。禮拜五下午五點,加六十個小時……禮拜一,早上五點。 | 時間軸動畫:從週五 17:00 往右推 60 格,停在週一 05:00,跟第二章的警報畫面疊在一起 |
| **旁白**:阿樹安靜了三秒。 | 阿樹石化,背景飄過一片落葉 |
| **阿樹**:那如果我沒扣那十 bar,四千除以一千四百四十,二點七八天,大約六十七個小時,是禮拜一中午十一點多。 | 白板旁邊用灰色寫錯誤版:4000 ÷ 1440 ≈ 2.78 天 ≈ 67 小時。時間軸上出現一條灰色虛線延伸到週一 11:40 |
| **陳師傅**:所以你才覺得撐得過去。就差那十 bar,差了快七個小時。 | 時間軸上兩個終點之間標出「差約 7 小時」,週一 08:00 剛好夾在中間 |
| **陳師傅**:而且這還只是估計。溫度一變,錶就跟著變;機台的用量不會永遠剛好一公升;管路有一點小漏,你也不知道。所以回答的時候要說「大約」,而且往保守的那邊說。 | 三個小圖示依序出現:溫度計、忽大忽小的流量曲線、接頭冒小泡泡。阿樹把「2.5 天」改寫成「**大約** 2.5 天」 |
| **阿樹**:那禮拜五,我應該怎麼回答課長? | 阿樹拿出小本子準備抄 |
| **陳師傅**:「照現在的用量,大約撐到禮拜一清晨,撐不到你們上班,所以我今天先換。」一句話,有數字,有前提,有動作。 | 字卡三個勾:✔ 數字 ✔ 前提 ✔ 動作 |
| **旁白**:整理一下,其實只有三步。第一步,算可用的氣:水容積,乘上目前壓力減換瓶壓力。第二步,算一天的用量:流量乘一千四百四十。第三步,相除。 | 白板整理成三行:① 40 × (100 − 10) = 3600 L ② 1 × 1440 = 1440 L/天 ③ 3600 ÷ 1440 = 大約 2.5 天 |

## 第六章 隔壁那一瓶,不能這樣算(6:50–8:10)【故事 + 教學】

| 旁白或台詞 | 畫面 |

## 重點整理(片尾卡)

**一行公式**

> 大約可用天數 ≈ 水容積(L)×(目前錶壓 − 換瓶壓力)(bar)÷ 每日用量(標準公升/天)
> 其中 每日用量 = 流量(slpm)× 60 × 24 = 流量 × 1440

**本集範例**:40 L ×(100 − 10)bar = 3,600 L;1 slpm × 1,440 = 1,440 L/天;3,600 ÷ 1,440 = **大約 2.5 天(約 60 小時)**

**五個重點**

1. 先讀兩個數字:瓶肩鋼印上的水容積,和壓力錶的讀數(先確認單位)。
2. 壓縮氣體的存量大致跟壓力成正比;錶上讀的是錶壓,絕對壓力要再加約 1 bar。
3. 鋼瓶不能用到零:要扣掉換瓶壓力(管線需求 + 保留正壓防止污染)。
4. 液化氣體(例如二氧化碳)不能看壓力,要秤重:現在重量 − 空瓶重量。
5. 算出來的是估計值:回答要說「大約」,警報點和週五檢查都要留安全餘裕。
