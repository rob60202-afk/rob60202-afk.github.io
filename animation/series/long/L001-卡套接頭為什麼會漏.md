# L001　卡套接頭為什麼會漏?

## 1. 基本資料

| 項目 | 內容 |
|---|---|
| 正式標題 | 卡套接頭為什麼會漏?師傅把它拆開給你看 |
| 測試標題 A | 「我明明鎖很緊啊!」菜鳥工程師的四十顆接頭 |
| 測試標題 B | 雙卡套接頭拆解:它根本不是靠螺紋密封的 |
| 測試標題 C | 一又四分之一圈:鎖太緊和鎖太鬆,為什麼都會漏 |
| 給觀眾的承諾 | 看完這十分鐘,你會知道雙卡套接頭靠哪裡密封,以及從切管到鎖緊,每一步做錯會怎麼漏。 |
| 目標觀眾 | 剛進現場的配管新人、儀電與設備工程師、帶新人的領班,以及對工程現場好奇的一般觀眾 |
| 類型 | 零件拆解 + 工具拆解 |

| 固定角色 | 阿樹(菜鳥氣體配管工程師,認真、容易臉紅)、陳師傅(資深領班,冷靜、冷面笑匠、用問題教人) |
| 場景 | 虛構晶圓廠的二次配現場,一條氮氣支管。Q 版卡通風格。 |

### 第五章　一又四分之一圈(5:30–7:10)【教學,以問答推進】

| 旁白或台詞 | 畫面 |
|---|---|
| **陳師傅**:好,現在來鎖。你平常鎖到什麼時候停? | 陳師傅遞給阿樹兩支扳手。 |
| **阿樹**:鎖到……手感覺很緊? | 阿樹握扳手,手臂冒青筋。 |
| **陳師傅**:你的很緊,跟我的很緊,一樣嗎?早上的你,跟下午五點的你,一樣嗎? | 分割畫面:早上精神飽滿的阿樹/傍晚累垮的阿樹。 |
| **阿樹**:……不一樣。 | 阿樹低頭。 |
| **陳師傅**:所以不靠手感,靠圈數。 | 字卡「不靠手感,靠圈數」。 |
| **旁白**:標準做法。一,管子插到底,螺帽用手轉到轉不動,這叫手緊。 | 【步驟圖 9-1】手轉螺帽,標字「手緊」。 |
| **旁白**:二,在螺帽的六點鐘方向,畫一個記號。 | 【步驟圖 9-2】接頭正面疊上時鐘面,六點鐘位置畫一點。 |
| **旁白**:三,一支扳手固定本體,另一支轉螺帽。本體不能跟著轉。 | 【步驟圖 9-3】兩支扳手,本體那支標「固定」,螺帽那支標「轉」。 |
| **旁白**:四,從手緊開始,轉一又四分之一圈。記號從六點鐘繞一整圈,再多走四分之一,停在九點鐘。 | 【步驟圖 9-4】記號沿時鐘面走一圈又四分之一,軌跡以弧線顯示,停在九點鐘。畫面字:1¼ 圈 → 9 點鐘。 |
| **阿樹**:我來試一顆。六點鐘……一圈……再四分之一。九點鐘,停。 | 阿樹嘴巴念著,慢慢轉扳手,記號停在九點鐘。 |
| **陳師傅**:感覺怎麼樣? | 陳師傅在旁邊喝茶。 |
| **阿樹**:比我以為的還要多轉。我之前有幾顆,可能根本沒到。 | 阿樹看著自己的手,冒冷汗。 |
| **陳師傅**:所以才要畫記號。不畫,你轉到一半被叫去接個電話,回來就不知道自己轉到哪了。 | 小劇場:阿樹接完電話回來,對著接頭發呆。 |
| **阿樹**:每一種尺寸都一樣嗎? | 阿樹舉手發問。 |
| **陳師傅**:好問題。四分之一吋到一吋,也就是六到二十五毫米,是一又四分之一圈。更小的,像十六分之一、八分之一、十六分之三吋,只要四分之三圈,停在三點鐘。 | 【對照表 10】兩列:1/4"–1"(6–25 mm)→ 1¼ 圈,9 點鐘;1/16"、1/8"、3/16"(2、3、4 mm)→ ¾ 圈,3 點鐘。 |
| **陳師傅**:不過這是常見的原廠數字。你手上那個牌子、那個系列,以它的安裝說明為準。超過一吋的,是另一套做法。 | 表格下方出現一行字:以該產品的原廠安裝說明為準。 |
| **阿樹**:那我多鎖一點,不是更保險嗎? | 阿樹比出「多轉一圈」的手勢。 |
| **陳師傅**:鎖過頭,卡套和管子被壓得太深,管子會縮口,螺紋會受傷,以後能拆裝的次數也變少。而且從外面看不出來。 | 【剖面圖 11 左】過緊:卡套陷得太深,管子內徑縮小,螺紋出現裂痕圖示。 |
| **阿樹**:那少鎖一點呢? | 阿樹改比「少轉」的手勢。 |

## 4. 重點整理(結尾卡的 5 點)

1. **靠卡套密封,不是靠螺紋。** 前卡套管密封,後卡套管抓牢,螺帽只負責往前推。
2. **鎖之前先做四件事:** 切直、內外去毛邊並清屑、檢查刮痕、插到底後畫線。
3. **不靠手感,靠圈數。** 手緊後,1/4"–1"(6–25 mm)轉 1¼ 圈;1/16"、1/8"、3/16"(2、3、4 mm)轉 ¾ 圈。一律以該產品的原廠安裝說明為準。
4. **間隙規只用在第一次組裝。** 塞得進去代表鎖不夠;它抓不到鎖過頭。拆過的接頭要靠拆前畫的記號裝回去,不能再轉 1¼ 圈。
5. **不混廠牌、不帶壓動接頭。** 本體、卡套、螺帽同廠牌同系列;要拆要鎖,先洩壓。

| B7 | 第四章:手緊後貼著螺帽後緣在管子上畫線,拿扳手前確認線還貼著螺帽。 | 首次組裝的畫線位置沒有查到原廠逐字依據。來源 14 的搜尋摘要提到原廠訓練教材建議用「深度標記工具」確認到底,那是插入前先在管子上做記號的專用工具,做法與腳本不同。請 Rob 決定腳本要用哪一種。另外,鎖緊後螺帽會前進,線與螺帽之間本來就會多出一小段,畫面不要誤導成「鎖完線要貼齊」。 |
| B8 | 第四章:「順著管子方向的刮痕」特別容易漏。 | 來源只說刮痕不利密封,沒有區分方向。縱向刮痕較危險是常見說法,未查到來源。 |
| B9 | 第五章:鎖過頭會造成「管子縮口、螺紋受傷、可拆裝次數變少,且外觀看不出來」。 | 來源 5、19 支持「過緊會損傷卡套與管子、縮短壽命」;縮口與螺紋受傷是我補充的具體現象,未查到逐字來源。 |
| B10 | 第五章:鎖不夠時「今天測壓也許過得了,之後一震動、一升壓就漏,嚴重時管子會被推出來」。 | 來源支持「鎖不夠會漏」。管子被推出與「測壓可能先過」是常見說法,未查到來源。這句牽涉安全,請特別確認。 |
| B11 | 第五章:「超過一吋的是另一套做法」。 | 搜尋只確認原廠另有一份一吋以上專用的安裝說明(來源 21),內容我沒讀到,所以腳本刻意不講細節。 |
| B12 | 第五章:手緊的定義「用手轉到轉不動」。 | 原廠用語是手緊,沒有查到更精確的定義。搜尋摘要另提到,原廠對高壓或高安全係數系統有不同的起始點(鎖到管子用手轉不動、也無法軸向移動後再開始算圈數,來源 1、3),腳本沒有納入。若本頻道觀眾的場合適用,請告知是否要補。 |
| B13 | 第六章:間隙規「不能拿別家的來量」。 | 來源顯示各廠有自己的檢查規,但沒有查到「不可跨廠使用」的逐字說法,屬合理推論。 |
| B14 | 第六章:重複組裝時「再轉一圈多就是鎖過頭」。 | 由 A6 的做法推論而來。派克的資料(來源 9)提到多次重複組裝後螺帽只需比原記號再前進一點點(摘要寫 10–20 度),方向一致,但請確認說法。 |
| B15 | 第七章:處置方式為「切掉那一小段管子,換上新的螺帽和卡套重做」。 | 沒有查到來源,是我依現場常理寫的。本體是否可沿用、管長不夠時怎麼辦,請 Rob 確認。 |
| B16 | 第七章:用測漏液逐顆檢查。 | 無塵室內是否允許使用測漏液、或應改為氦氣測漏,沒有查證。請依實際現場習慣調整畫面。 |
| B17 | 全片:沒有提到管材硬度、壁厚與氣體用途的選管要求。 | 這些會影響卡套能否咬住管子,但超出本集範圍,也未查證,所以沒寫。若 Rob 認為必須帶一句,請補。 |
| B18 | 第六章:「很多接頭是三個月後才漏」。 | 戲劇化說法,沒有來源,三個月不是數據。若覺得誤導,可改成「過一陣子才漏」。 |
| B19 | 第七章:四十顆裡有四顆鎖不夠。 | 純劇情設定,不是統計數字。 |
