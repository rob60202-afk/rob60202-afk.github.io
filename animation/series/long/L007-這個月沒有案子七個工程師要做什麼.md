# L007 這個月沒有案子,七個工程師要做什麼?

| 欄位 | 內容 |
|---|---|
| 主標題 | 這個月沒有案子,七個工程師要做什麼?週報不寫待命,寫交出了什麼 |
| 測試標題 A | 週報寫了七個「待命」,經理只問一句:在等什麼? |
| 測試標題 B | 沒案子的一個月:七個工程師、四個專案,交出了什麼 |
| 測試標題 C | 工程師的績效指標怎麼訂?結果你決定不了,過程你可以 |
| 給觀眾的一句承諾 | 看完這十分鐘,你會把沒案子的時間,排成有交付物、有期限、有負責人的基礎建設專案;用可控的過程指標追進度,週報寫「交出了什麼」,用固定五段向主管回報,也知道指標最常掉進的三個陷阱。 |
| 目標觀眾 | 剛升課長、組長的工程師;遇到淡季、要向上交代團隊在做什麼的現場主管;要替工程師訂績效指標的主管;想知道週報怎麼寫才有用的工程師。 |
| 類型 | 故事 + 流程教學 + 計算拆解 |
| 預估長度 | 約 10 分鐘(旁白與台詞共 2,750 字,以程式計數,只計中文字與數字,不含標點與說話者名稱;另有英文字母 30 個,幾乎都是工程師代號 A 到 G;平均每分鐘 275 字,各章語速見製作備註) |
| 固定角色 | 阿樹(配管工程公司的工程師,剛升課長,底下帶七個工程師;認真、容易臉紅)、陳師傅(公司的資深領班;冷靜、冷面笑匠、用問句教人) |
| 其他角色 | 經理(阿樹的主管;話不多、講話直接,但一直站在阿樹這邊)、工程師 A 到 G(阿樹課裡的七個人)、採購(只出現在畫面)、舊客戶的廠務承辦(現勘與電話畫面)。業務與老闆只在旁白和台詞裡提到。 |
| 設定 | 虛構的配管工程公司(乙方)。這一季案量少,阿樹的課這個月沒有在施工的案子。經理要阿樹每週五交一份「七個人在做什麼」,一個月內提出課的下半年績效指標。Q 版卡通風格。 |

> 全片為虛構故事,不使用任何真實公司、業主、人名與品牌。片中的人數、件數、筆數、時數、天數與比例,都是為了方便心算而編的示意數字,不是任何公司的制度或標準;績效指標要訂哪些項目、目標值多少,實際依公司與團隊情況設定。第 4 章由旁白完整說一次,第 7 章再提醒一次「目標值依公司與團隊情況設定」;從第 4 章起以右上角角標常駐顯示。本片不談指標與考績、獎金、工時等勞動條件的關係。

## 重點整理(結尾卡五個重點)

1. 沒案子的時間,用可控的過程指標交代:圖面審查、現場勘查紀錄、估價資料整理、包商單價、缺失改善、標準作業文件、材料清單標準化、教育訓練。結果指標(營收、得標、毛利)還是要看,但不能只看結果。
2. 每一件事都要接得回部門目標。課長把方向翻成專案,每個專案要有交付物、期限、負責人;一個人一個主要專案,資深帶新人。
3. 週報寫「交出了什麼」,不寫「忙了什麼」:東西的名字、數量、誰可以拿去用。沒做完的照實寫卡在哪裡、需要誰幫忙;最後填案件、基礎建設、教育訓練的工時。
4. 給主管一頁,固定五段:本週完成(只寫成果)、目前風險(和處理方式)、下週推進(和負責人)、需要主管協助(寫最晚日期)、人力配置。
5. 指標的三個陷阱:變成打勾比賽、只追數量不看品質、設了做不到的目標。每個數量配一個品質條件;目標從現況出發、跳一下搆得到,每個月檢討。指標項目與目標值,依公司與團隊情況設定。
