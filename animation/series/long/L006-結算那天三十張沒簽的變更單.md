# L006 結算那天，三十張沒簽的變更單

| 欄位 | 內容 |
|---|---|
| 主標題 | 結算那天，三十張沒簽的變更單：現場說好的，為什麼一張都不算 |
| 測試標題 A | 現場說好的追加，結算那天一張都不算 |
| 測試標題 B | 六十萬的變更單沒人簽，答應的承辦上個月調走了 |
| 測試標題 C | 變更追蹤表每週記、每月對：結算那天，不該有新聞 |
| 給觀眾的一句承諾 | 看完這十分鐘，你會分得清「現場指示」和「核定的變更單」，會用一張變更追蹤表每週記、每月跟甲方對，也知道手上已經堆了一疊沒簽的單子時，第一步該做什麼。 |
| 目標觀眾 | 剛開始自己帶案子的工程師、工地主任與現場主管；小型工程行的業務與會計；想知道承包商怎麼管變更的業主承辦。 |
| 類型 | 故事 + 流程教學 + 話術示範 |
| 預估長度 | 約 10 分鐘（旁白與台詞共 2,700 字，以程式計數，只計中文字與數字，不含標點與說話者名稱；各章語速見製作備註） |
| 固定角色 | 阿樹（小型配管工程行的工程師，剛升課長；認真、容易臉紅）、陳師傅（公司的資深領班；冷靜、冷面笑匠、用問句教人） |
| 其他角色 | 甲方原承辦（施工期間的窗口，結算前一個月調到別的廠區）、甲方新承辦、甲方採購、丙方班長、老闆 |
| 設定 | 虛構的小型配管工程行（乙方），承包客戶（甲方）一條新產線的冷卻水與壓縮空氣配管，合約未稅三百萬，施工三個月。工班由配合的丙方派。甲方在現場的窗口是承辦，付款要看採購的訂單。Q 版卡通風格。 |

> 全片為虛構故事，不使用任何真實公司、業主、人名與品牌。所有金額都是為了方便心算而編的未稅整數，不是市場行情。這句話在第 1 章與第 6 章各說一次，並全程以角標顯示。

## 第 2 章　叫你做，跟同意付錢，是兩件事（1:15–2:45）【教學】

| 旁白或台詞 | 畫面 |
|---|---|
| 旁白：師傅在白板上畫了四格，像四階樓梯。 | 工務所白板。陳師傅畫出往上的四階【圖 A】。 |
| 旁白：第一格，現場指示。甲方在現場說：這樣改。說的人通常是承辦、廠務工程師，有的案子是監造。他們決定怎麼做，但不一定能決定付多少。 | 【圖 A】第一格亮起：一個戴安全帽的人指著管線。下方小字「通常：承辦／廠務工程師／監造」。 |
| 旁白：第二格，變更申請。乙方用書面寫下來：改了什麼，為什麼，數量多少，請甲方確認事實。 | 第二格亮起：一張申請單，「改什麼／為什麼／數量」三欄依序打勾，下方一格「甲方確認」。 |
| 旁白：這一格最常被跳過。可是只要送出去，甲方回一句收到，就留下你當時有提出的紀錄，不是結算才想到。 | 申請單蓋上一個「已收到　3/13」的小戳記，旁邊的日曆停在三月，不是七月。 |
| 旁白：第三格，變更報價。合約裡有的項目，照合約的單價；沒有的，另外報價。技術和數量，通常是承辦或主管看；價格，通常是採購談。 | 第三格亮起：報價單左半「合約單價」、右半「另行報價」。旁邊兩個小人像：「主管看數量」「採購談價格」。 |
| 旁白：第四格，核定的變更單。甲方有權限的人核准，採購出變更訂單，或補一份合約。走到這一格，才是可以請款的錢。 | 第四格亮起，蓋下一枚印章，出現一張「變更訂單」。一條金色的線從第四格連到「請款」。 |
| 旁白：誰能簽哪一格，每家公司不一樣。有的看金額，有的看部門。 | 【圖 A】下方字卡：「誰能簽哪一格，依甲方內部的核決權限，各公司不同」。 |
| 旁白：最好走到第四格再動工。現場等不及的，第一格至少要留下文字，後面三格盡快補上。 | 第一格旁貼上一張便條「先留文字」，箭頭往上指向後三格「盡快補」。 |
| 陳師傅：你的三十張，停在第幾格？ | 陳師傅把馬克筆遞給阿樹。 |
| 阿樹：……第一格。 | 阿樹把三十張單子的縮圖全部貼在第一格，堆到滿出來，後面三格空空的。 |
| 旁白：口頭說好，為什麼這麼不牢靠？人會調走。記憶會不一樣。說的人不一定有權限。而且當時，沒有數量，也沒有價格。 | 【圖 B】四個圖示依序出現：空座位、兩個內容不同的對話泡泡、一把鑰匙、空白的「數量／價格」欄。 |
| 陳師傅：叫你做的人，跟能決定付錢的人，常常不是同一個。 | 陳師傅在第一格和第四格之間，畫一條長長的虛線。 |
| 旁白：所以開工會議那天，就要問清楚：誰能下指示，誰能簽變更，多少錢以上要誰簽。 | 【圖 C】開工會議三個問題，逐一亮起。 |

## 第 3 章　指示的那一刻（2:45–4:00）【故事＋教學】

| 旁白或台詞 | 畫面 |
|---|---|
| 旁白：師傅要阿樹回想三月那一次。回水管跟風管打架。 | 回憶畫面：廠房內，回水管的預定路線被一條大風管擋住。原承辦和阿樹都戴安全帽，站在地面走道上抬頭看。 |
| 甲方原承辦：這段改走樑下面吧。 | 原承辦指著樑下方的空間。 |
| 旁白：當時的阿樹，只回了一個好。現在，把那一刻重來一次。 | 倒帶效果，回到原承辦開口之前。字卡：「重來一次」。 |
| 旁白：第一，留下文字。當場請承辦在訊息裡打一句，或是你自己傳一則確認。 | 阿樹退到走道邊、不在作業區內，用手機打字。通用聊天介面，沒有任何商標。 |
| 阿樹：剛剛您在現場指示，回水管改走樑下。我們理解如下，有出入請告訴我。 | 訊息逐字出現，下面附三行：「改走樑下」「預估多 16 米、彎頭 4 顆」「照片 4 張」。 |
| 旁白：重點是對方的回覆。一句「對，照這樣做」，比十張自己寫的單都有用。 | 原承辦的回覆跳出來：「對，照這樣做」，泡泡放大發亮。 |
| 旁白：對方忙到沒有回，也要傳。隔天的週會再提一次，請甲方寫進會議紀錄。 | 甲方週會的投影畫面，會議紀錄第 4 項打出「回水管改走樑下」。 |
| 旁白：第二，照片。改之前、改之後，同一個角度拍，看得出位置和日期。 | 【圖 D】左右兩張照片，以同一根柱子當參考：左「施工前」、右「施工後」，角落有日期與位置編號。 |
| 旁白：第三，數量。當場量，最好跟甲方一起量。等包了保溫、封了天花板，就量不到了。 | 阿樹和原承辦站在地面，用雷射測距儀量樑下的放樣記號，顯示「16 m」。旁邊一格預告：管子被保溫包住，彎頭看不見了。 |
| 旁白：第四，施工日報。當天寫下誰指示、改了什麼，請甲方現場人員簽名。 | 施工日報特寫，「甲方指示事項」欄寫著這一筆，下方有甲方人員的簽名。 |
| 旁白：這四樣，當天做，十分鐘。等到結算才補，很多已經補不回來了。 | 左邊一個小時鐘只走了十分鐘；右邊一個空的資料夾，標籤寫著「結算才補」。 |
| 陳師傅：還少一樣。為什麼改？ | 回到現在，工務所。陳師傅敲敲桌面。 |
| 阿樹：因為跟風管打架？ | 阿樹不太確定地舉手。 |
| 陳師傅：是圖畫錯，是甲方要改，還是我們自己裝錯？原因，決定誰付錢。 | 【圖 D】右側三個選項：「圖面問題」「甲方要求」「我們自己的錯」，最後一個旁邊畫一個乙方的小錢包。 |
| 旁白：訊息算不算數，要看合約怎麼寫。所以訊息只是先把事實留住，正式的單還是要補。 | 字卡：「訊息先留住事實，正式的單還是要補」。下方小字：「效力依合約約定」。 |

## 第 4 章　一張每週更新的表（4:00–5:15）【教學】

| 旁白或台詞 | 畫面 |
|---|---|

| 旁白：一列一件變更。編號、日期、誰提出、改了什麼、為什麼。 | 【表 2】前五欄亮起。 |

| 旁白：狀態分五步：指示、已提出、已報價、已核定、已請款。前四步就是剛剛那四格，最後一步，是錢真的請到了。 | 【圖 E】五個色塊排成一條路，前四個用虛線對到【圖 A】的四格；另有一條灰色岔路「不成立」。 |
| 陳師傅：減的也要寫。 | 陳師傅指著表格最下面的空白列。 |
| 阿樹：減的？ | 阿樹愣住。 |
| 陳師傅：甲方取消的那一支，甲方自己買的閥。你不寫，他也記得。到時候你加的每一張，他都會多看兩眼。 | 想像畫面：甲方承辦拿著放大鏡，一張一張檢查阿樹的追加單。 |
| 旁白：追減，就是金額前面加一個負號。一樣要編號，一樣要簽。 | 【表 2】新增一列，編號「D-01」，金額欄是紅色的「−40,000」。 |
| 旁白：這張表每週更新一次。每週一早上十五分鐘，把上週的指示、照片編號、日報日期補進去。 | 週一早上的工務所，阿樹端著咖啡，把手機裡上週的照片編號一筆一筆填進表裡。 |

| 陳師傅：承辦會調走，你會忘記。這張表不會。 | 陳師傅存檔，檔名「變更追蹤表_每週更新」。 |

## 第 5 章　每個月，跟甲方對一次（5:15–6:20）【故事＋教學】

| 旁白或台詞 | 畫面 |
|---|---|
| 旁白：每週自己記，還不夠。師傅要阿樹想像另一個三月底。 | 畫面邊框變成虛線，表示想像。月曆翻回三月底，畫一個圈。 |
| 旁白：每個月固定一天，跟承辦坐下來半小時，拿著追蹤表一列一列看。看四件事。 | 甲方會議室（室內不戴安全帽）。阿樹和原承辦並肩看同一張印出來的追蹤表。 |
| 旁白：一，這個月新增的追加和追減。二，還沒簽的，卡在誰，還缺什麼，哪天可以好。 | 【圖 F】四張卡片的前兩張亮起。 |
| 旁白：三，有爭議的，記下雙方的說法和要補的資料，會上不爭對錯。四，已經核定的，有沒有進到這個月的請款。 | 【圖 F】後兩張亮起。第三張卡片上，兩個不同顏色的對話泡泡並排。 |
| 甲方原承辦：這張超過我的權限，要我們課長簽。 | 原承辦指著其中一列，表情坦白。 |
| 阿樹：好，資料我整理給課長。您方便幫我約個時間嗎？ | 阿樹在那一列的「甲方簽核人」欄寫上「課長」，旁邊註明約好的日期。 |
| 旁白：超過權限的，不是去逼承辦簽，是請他告訴你，該找誰。 | 一個箭頭從承辦往上指向「課長」，旁邊沒有任何驚嘆號。 |

## 重點整理（結尾卡五個重點）

1. 現場指示不等於核定的變更。指示、申請、報價、核定四格，只有走到核定的那一格，才是可以請款的錢。誰能簽哪一格各公司不同，開工會議就要問清楚。
2. 指示的那一刻留下四樣東西：對方回覆的文字、施工前後同角度的照片、當場（最好會同甲方）量的數量、甲方簽名的施工日報。再寫下改的原因，原因決定誰付錢。
3. 一張變更追蹤表，追加、追減都記，每週更新：編號、日期、誰提出、改了什麼、為什麼、數量、單價或一式、金額、狀態、甲方簽核人、簽核日期、佐證。
4. 每個月跟甲方對一次：新增的、卡住的、有爭議的、已核定還沒請款的。對完當天寄紀錄，請對方回覆確認。結算那天，不該有新聞。
5. 已經堆了一疊：先拿掉自己的，再照證據分疊、把追減列進來、附證據做總表；有書面的請甲方確認事實，中間的拿出來談，只有記憶的自己放手。能請多少、多久內要提出，最後看合約；不確定就先問公司的法務或合約人員。
