## 第 2 章　叫你做的人，跟能決定付錢的人（1:15–2:35）【教學】

| 旁白或台詞 | 畫面 |
|---|---|
| 旁白：師傅在白板上畫了四格，像四階樓梯。 | 工務所白板。陳師傅畫出往上的四階【圖 A】。 |
| 旁白：第一格，現場指示。甲方在現場說：這樣改。說的人通常是承辦，也常是使用單位的工程師，有的案子是監造。他們決定怎麼做，但不一定能決定付多少。 | 【圖 A】第一格亮起：一個戴安全帽的人指著管線。下方小字「通常：承辦／使用單位的工程師／監造」，再一行小字「機台廠商、使用單位直接叫你改的，先回承辦確認」。 |
| 旁白：第二格，變更申請。乙方用書面寫下來：改了什麼，為什麼，數量多少，要不要多幾天，請甲方確認事實。 | 第二格亮起：一張申請單，「改什麼／為什麼／數量／工期」四欄依序打勾，下方一格「甲方確認」。 |
| 旁白：這一格最常被跳過。可是只要送出去，甲方回一句收到，就留下你當時有提出的紀錄，不是結算才想到。 | 申請單蓋上一個「已收到　3/13」的小戳記，旁邊的日曆停在三月，不是七月。 |
| 旁白：第三格，變更報價。合約裡有單價的，照合約單價；沒有的，另外報價。技術和數量，通常是承辦或主管看；價格，通常是採購談。 | 第三格亮起：報價單左半「合約單價」、右半「另行報價」。旁邊兩個小人像：「主管看數量」「採購談價格」。第二、三格之間小字：「小變更，第二、三格常是同一張追加報價單」。 |
| 旁白：第四格，核定的變更單。甲方有權限的人核准，採購出變更訂單，或補一份合約。走到這一格，請款才過得了。 | 第四格亮起，蓋下一枚印章，出現一張「變更訂單」。一條金色的線從第四格連到「請款」。【圖 A】下方字卡：「誰能簽哪一格，依甲方內部的核決權限，各公司不同」。 |
| 旁白：最好走到第四格再動工。等不及的，至少要有甲方的文字同意先做，後面三格盡快補上。 | 第一格旁貼上一張便條「甲方文字：同意先做」，箭頭往上指向後三格「盡快補」。字卡小字：「能不能先做、怎麼同意，依合約與甲方規定」。 |
| 陳師傅：你的三十張，停在第幾格？ | 陳師傅把馬克筆遞給阿樹。 |
| 阿樹：……第一格。 | 阿樹把三十張單子的縮圖全部貼在第一格，堆到滿出來，後面三格空空的。 |
| 陳師傅：叫你做的，跟出錢的，常常不是同一個人。 | 陳師傅在第一格和第四格之間，畫一條長長的虛線。 |
| 旁白：所以開工會議那天，就要問清楚：誰能下指示，變更用什麼文件、送給誰，多久內要提出。 | 【圖 C】開工會議三個問題，逐一亮起，最後蓋上「寫進開工會議紀錄」。第三題旁小字：「合約的提出期限：＿天」。 |

## 第 3 章　指示的那一刻（2:35–4:00）【故事＋教學】

| 旁白或台詞 | 畫面 |
|---|---|
| 旁白：師傅要阿樹回想三月那一次。回水管跟報價後才裝的風管打架。 | 回憶畫面，色調偏暖：廠房內，回水管的預定路線被一條新裝的大風管擋住。字卡：「空調廠商在報價後才裝，報價時圖上與現場都沒有」。原承辦和阿樹都戴安全帽、扣好頤帶、穿安全鞋，站在地面走道上抬頭看；頭頂上方沒有人在作業。 |
| 甲方原承辦：這段改走樑下面吧。 | 原承辦指著樑下方的空間。 |
| 旁白：當時的阿樹，只回了一個好。現在，重來一次。 | 倒帶效果，回到原承辦開口的那一刻。字卡：「重來一次」。從這裡到「回到現在」之前，畫面邊框用虛線，表示假設。 |
| 阿樹：好，可以改。這段算追加喔，我等一下傳給您。 | 原承辦（無聲）再說一次「這段改走樑下面吧」；阿樹在走道上當面回答，原承辦點頭。 |
| 旁白：第一，留下文字。用甲方允許的管道，請承辦打一句，或是你自己傳一則確認。 | 阿樹退到走道邊、不在作業區內，用手機打字。通用聊天介面，沒有任何商標，角落標「甲方允許的通訊管道」。字卡：「廠區拍照、傳訊息依甲方資安規定，很多廠區要先申請」。 |
| 阿樹：剛剛現場講的，回水管改走樑下，預估多 16 米、彎頭 4 顆。這段會列追加，報價另送，有出入請告訴我。 | 訊息逐字出現，下面附四行：「改走樑下」「預估多 16 m、彎頭 4 顆、吊架 4 組」「列追加，報價另送」「照片 4 張」。 |
| 旁白：重點是對方的回覆。一句「對，照這樣做」，比十張自己寫的單都有用。 | 原承辦的回覆跳出來：「對，照這樣做」，泡泡放大發亮。字卡：「訊息寫了『列追加』，他回的『對』，才不只是同意改做法」。 |
| 旁白：對方沒回，也要傳。隔天週會再提一次，請甲方寫進會議紀錄。 | 甲方週會的投影畫面，會議紀錄第 4 項打出「回水管改走樑下（列追加，報價另送）」。 |
| 旁白：第二，照片。照甲方的規定拍，改之前、改之後，同一個角度，看得出位置和日期。 | 【圖 D】左右兩張照片，以同一根柱子當參考：左「施工前」、右「施工後」。畫面裡放一塊小白板，寫日期、位置、單號；角落有照片編號。照片裡的人一樣全套防護具。 |
| 旁白：第三，數量。當下先估，做完找甲方一起量。天花板一封、產線一開，就上不去了。 | 三格並排。左格：指示當下，阿樹看著圖估「約 16 m」。右格：做完當天，阿樹和原承辦站在地面，沿著地上的放樣墨線，用雷射測距儀從柱子量到柱子、分段加總，顯示「16 m」。預告格：天花板封板，門口掛著「生產中　禁止進入」。 |
| 旁白：第四，施工日報或工作許可單。當天寫下誰指示、改了什麼，請甲方簽名。 | 施工日報與甲方的工作許可單並排特寫：日報「甲方指示事項」欄寫著這一筆；許可單作業內容寫「追加：回水管改走樑下（甲方承辦要求）」，下方有甲方人員簽名。字卡：「簽的是當天的事實，不是同意加錢；甲方不簽的，請他寫進週會紀錄」。 |
| 旁白：這四樣，每樣幾分鐘。等到結算才補，很多已經補不回來了。 | 左邊一個小時鐘只走了幾分鐘；右邊一個空的資料夾，標籤寫著「結算才補」。 |
| 陳師傅：還少一樣。為什麼改？ | 回到現在，工務所，虛線邊框消失。陳師傅敲敲桌面。 |
| 阿樹：因為跟風管打架？ | 阿樹不太確定地舉手。 |
| 陳師傅：是甲方的圖畫錯，是甲方要改，還是我們沒先看現場？原因，決定誰付錢。 | 【圖 D】右側三個選項：「甲方圖面錯誤」「甲方要求」「我們自己的錯」，最後一個旁邊畫一個乙方的小錢包，小字「沒先看現場、報價前看得到的，通常也算這格」。 |
| 旁白：訊息只是先留住事實，正式的單還是要補。能不能當正式的變更，看合約和甲方規定。 | 字卡：「訊息先留住事實，正式的單還是要補」。下方小字：「效力依合約約定與現行法規」。 |

## 第 4 章　一張每週更新的表（4:00–5:12）【教學】

| 旁白或台詞 | 畫面 |
|---|---|
| 旁白：證據留下來，要有地方放。師傅的舊本子，阿樹打成了一張表，叫變更追蹤表。 | 陳師傅從口袋掏出一本手畫格子的舊本子，一行一件，寫得密密麻麻。下一格，阿樹在電腦上照著建出【表 2】變更追蹤表。 |
| 旁白：一列一件變更，十二欄，畫面上都有。最要緊的是：為什麼、數量、申請和核定的金額、佐證。 | 【表 2】十二欄的欄位標題一起滑進來；念到的「為什麼」「數量」「申請金額」「核定金額」「佐證」五欄依序亮起。佐證欄的編號點開，跳出照片和訊息的縮圖。 |
| 旁白：拿三月那一張來填：承辦提出，回水管改走樑下，原因是跟新裝的風管衝突。十六米、彎頭四顆、吊架四組，照合約單價，五萬。當時這樣記，月底就能送去簽。 | 虛線邊框（假設畫面）。【表 2】第一列逐格填入，內容同附錄 A 的 V-03：16 m／4 顆／4 組，40,000 + 6,000 + 4,000 ＝ 50,000。 |
| 旁白：狀態分五步：指示、已提出、已報價、已核定、已請款。前四步就是剛剛那四格，最後一步，是真的列進了請款單。 | 【圖 E】五個色塊排成一條路，前四個用虛線對到【圖 A】的四格，第五個畫成一張請款單；另有一條灰色岔路「不成立」。 |
| 陳師傅：減的也要寫。 | 陳師傅指著表格最下面的空白列。 |
| 阿樹：減的？ | 阿樹愣住。 |
| 陳師傅：甲方取消的那一支，改叫機台廠商做的閥。你不寫，他也記得。到時候你加的每一張，他都會多看兩眼。 | 想像畫面：甲方承辦拿著放大鏡，一張一張檢查阿樹的追加單。 |
| 旁白：追減，就是金額前面加一個負號。一樣要編號，一樣要簽。甲方只供料、你照樣裝的，只扣材料。 | 【表 2】新增一列，編號「D-01」，金額欄是紅色的「−40,000」。字卡：「改由別人連工帶料做的：照單價扣／甲方只供料、乙方照樣安裝：只扣材料」。 |

## 重點整理（結尾卡五個重點）

1. 現場指示不等於核定的變更。指示、申請、報價、核定四格，走到核定的那一格，請款才過得了。誰能簽哪一格各公司不同；誰能下指示、變更用什麼文件、多久內要提出，開工會議就要問清楚，寫進會議紀錄。
2. 指示當天：當面講明會列追加，用甲方允許的管道留下對方回覆的文字，拍施工前照片，先估數量。做完當天：同角度的施工後照片、會同甲方量的實際數量、甲方簽名的施工日報或工作許可單。拍照與傳訊息依甲方規定。再寫下改的原因，原因決定誰付錢。
3. 一張變更追蹤表，追加、追減都記，每週更新：編號、日期（指示／提出）、誰提出、改了什麼、為什麼、數量、單價或一式、申請金額、核定金額、狀態、甲方簽核人與日期、佐證。
4. 每個月跟甲方對一次，排在請款截止前一週：新增的、卡住的、有爭議的、已核定還沒請款的。超過承辦權限的，問他往上簽還缺什麼。對完當天寄紀錄，請對方回一句收到。結算那天，不該有新聞。
5. 已經堆了一疊：先拿掉自己的，再照證據分疊、把追減列進來、附證據做總表；有書面的請甲方確認事實，中間的一張一張對，翻過紀錄仍看不出是甲方要的，自己吸收。結算要簽的文件，簽之前先給公司管合約的人看；能請多少、多久內要提出，依合約約定與現行法規。

| 編號 | 追加用 V、追減用 D，各自流水號，不重複、不跳號 | 結算時一張一張對得起來 |
| 日期（指示／提出） | 前面寫指示或事件發生的那一天，不是補單的那一天；後面寫書面申請送出的那一天 | 看得出是當時就提出，也看得出有沒有在合約期限內提出 |
| 誰提出 | 職稱加方式，例如「甲方承辦（現場口頭，當天訊息確認）」；使用單位或機台廠商直接叫的，寫明是誰，並註明有沒有回承辦確認 | 看得出指示的來源、有沒有文字、有沒有經過窗口 |
| 改了什麼 | 開頭標【追加】或【追減】，寫位置與內容；影響工期的，寫要多幾天 | 一眼分得出加或減；錢和工期一起追 |
| 為什麼 | 甲方要求／甲方圖面錯誤／報價時看不到的現場條件／乙方自己的錯，四選一再補一句；圖面問題要註明是甲方提供的圖，還是乙方自己畫的施工圖 | 原因決定誰付錢。乙方自己的錯（含自己畫的施工圖出錯）、報價前看得到的現場條件，通常不進請款；實際依合約 |
| 數量 | 實際量的數字，註明有沒有會同甲方量；改線、移位的，寫多出來的淨數量（新路線減原路線），不是整段重算 | 事後最難補的就是數量；原本合約裡那一段要先扣掉 |
| 單價或一式 | 合約有單價的寫「依合約單價」並列出單價；合約沒有的附報價單號，報價單上列數量與單價（或工、料分開），不要整筆只寫一式 | 價格有依據，甲方採購才審得下去；整筆一式最容易被要求拆開或砍價 |
| 申請金額 | 追加為正、追減為負，寫出算式 | 加總時不會漏掉減項 |
| 核定金額 | 核准文件上的金額；與申請不同時，在佐證寫原因 | 看得出申請和核定差在哪，結算時對得起來 |
| 狀態 | 指示／已提出／已報價／已核定／已請款／不成立，六選一 | 每週看一眼就知道卡在哪一格 |
| 甲方簽核人與日期 | 依甲方的核決權限，寫實際核准的人的職稱、文件號與核准文件上的日期；已核定才填 | 確認簽的人有權限 |
| 佐證 | 照片編號、訊息截圖編號、日報日期、工作許可單號、會議紀錄項次、報價單號、新版圖號與版次 | 結算時能在一分鐘內翻到證據；新版圖跟合約版一比，多出來的就是追加 |

### 狀態的意思

| 狀態 | 意思 | 對應片中的四格 |
|---|---|---|
| 指示 | 甲方在現場說了，乙方已經記錄並留下文字（最好有甲方的回覆） | 第一格：現場指示 |
| 已提出 | 書面變更申請已送出，有甲方簽收或回覆收到的紀錄（收到不等於確認事實；甲方確認事實的日期記在佐證） | 第二格：變更申請 |
| 已報價 | 報價已送出，等甲方審數量、談價格 | 第三格：變更報價 |
| 已核定 | 甲方有權限的人核准，採購已出變更訂單或補合約 | 第四格：核定的變更單 |
| 已請款 | 已列入當期請款（估驗）單，寫請款期別；收款另外記 | 四格之後 |
| 不成立 | 雙方確認不算變更，或乙方決定自行吸收，寫明原因後保留這一列，不刪除 | 岔路 |

### 使用規則

1. 每週一更新一次，跟週報一起交給主管。
2. 指示當週進表、送出變更申請，報價兩週內補上。這是本片陳師傅的公司規矩；合約如果對提出期限另有規定，依合約。
3. 追減和追加放在同一張表，一樣編號、一樣要簽，計價口徑也一樣：追加算了彎頭、吊架，追減也要扣。追減時，已經訂的料、已經做的工，另外列出來談。改由別人連工帶料做的，照單價扣；甲方只供料、乙方照樣安裝的，只扣材料費。
4. 拍照先照甲方規定：廠區內拍照要不要申請、能不能用自己的手機，先問清楚；不能拍的，請承辦用甲方核可的設備拍了傳給你。照片用同一個角度拍施工前後，畫面裡放一塊小白板，寫日期、位置、單號；檔名用照片編號。
5. 訊息用甲方允許的管道傳；能傳到專案群組就不要私訊，承辦調走了，紀錄也還在。截圖要看得到日期、時間、傳送人；原始對話保留，不刪；工作手機開備份，每個月把對話匯出存檔。照片與截圖只傳給這個案子相關的人。對方不方便打字時，可以用複寫聯單寫三行（改什麼、大約多少、算追加），請對方簽名，撕一聯給他。
6. 順便做的工作，一樣補開當天的施工申請或工作許可，作業內容寫「追加：○○（甲方○○要求）」。甲方簽了許可，安全有了，證據也有了。
7. 工班不直接接甲方的指示。使用單位或機台廠商直接叫工班改的，工班回一句「我跟阿樹講」，當天回報；阿樹再請承辦確認一句。
8. 丙方（工班）的追加也用同一套方法記，乙方跟丙方之間一樣每月對。點工單每天一張、當天簽：日期、人名、上下工時間、地點、做什麼、誰叫的；同一天的合約內工作和追加分開寫，混在一起，甲方會全算成合約內。待工時，人到了不能做，當下就傳訊息給承辦，寫明幾點開始待工，結束再傳一次。月底用每天的工具箱會議簽到表，或請甲方提供門禁紀錄，對一次人數。
9. 拆除的追加，要寫拆下來的東西歸誰：交還甲方，或經甲方同意由乙方清運，殘值怎麼算。
10. 合約追加減單價（本片示意，非行情）：配管每米 2,500（管材與安裝；彎頭、吊架另計）、彎頭每顆 1,500、吊架每組 1,000、球閥每顆 5,000（含安裝）、點工每人每日 5,000（同 L003）。本片只列一種配管單價，實際合約多半依管徑分列。這是和 L003 不同的合約：L003 的配管每米單價含管件與吊架。

## 附錄 C：兩種開口方式（並排）

情境：第 7 章，阿樹去見甲方新承辦之前，先對著扮演承辦的陳師傅練習；隔天用的是右邊的版本。兩個版本的台詞與片中逐字相同。台詞裡不用「承辦」稱呼對方；實際見面時，照現場習慣稱呼（例如「王先生」「李工」），或直接講。

| 甲方承辦聽到的 | 要我一次簽三十張沒看過、可能超過我權限的東西；不簽就拿文件威脅。最安全的回答只剩「照合約處理」。 | 對方先認自己沒有及時補單，先拿掉不該請的，主動列出追減；我只要確認看得到的事實，錢照程序走；超過我權限的，他會補齊資料讓我往上簽。 |

**行得通的版本，做對了五件事：**

1. 先認自己沒有及時補單，不怪調走的前任承辦。
2. 先拿掉自己的項目，主動列出追減，讓對方相信其他的數字。

4. 價格有合約單價的照單價，沒有的照甲方的程序議價。
5. 超過他權限的，問清楚往上簽要補什麼資料，並約好下一次。

同樣的五件事，也適用於平常每月對帳時請承辦確認新的變更，只是第 1 件可以省略。
