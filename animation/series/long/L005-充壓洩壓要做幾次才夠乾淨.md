# L005 充壓洩壓要做幾次才夠乾淨?

- **類型**:故事 + 計算拆解(長片,橫式 16:9,Q 版卡通)
- **主標題**:充壓洩壓要做幾次才夠乾淨?「老規矩三次」的三次,是怎麼來的
- **備選標題(測試用)**
  1. 「三次,收工!」隔天品管一量,沒過——菜鳥答不出為什麼是三次
  2. 新管線裡的空氣,充放三次還剩多少?一個比值、一個最常犯的錯
  3. 錶上的零,不是空的:吹淨次數為什麼一定要用絕對壓力算
- **給觀眾的一句承諾**:看完這支影片,你會算出一次充壓洩壓能把管子裡的氣稀釋成幾分之一、要做幾次才到目標,也會知道這個算法在哪些地方會讓你太樂觀。
- **目標觀眾**:剛進氣體配管、廠務、設備領域的新人與技術員;帶新人的領班;想弄懂「為什麼是三次」的工程師與理工學生。
- **預估長度**:約 10 分鐘(旁白與台詞 2,744 個中文字,以程式計數,不含標點、數字、英文單位與說話者標示;各章語速見下方「各章字數與語速」)
- **固定角色**:阿樹(氣體配管承攬商工班的菜鳥,認真、容易臉紅)、陳師傅(公司的資深領班,冷靜、冷面笑匠、用問題教人)。配角:工班前輩(不取名)、業主的品管(不取名)。
- **場景**:虛構晶圓廠的下層(Sub-Fab)。工班剛裝好一條新的氮氣管:從既有主管的閥接出來,一路拉到一台新機台的接點。中途有一個三通,分出一支預留給下一台機台的支管,已經拉到位,末端用閥封住(這就是片中的「盲管」)。
- **服裝**:所有在現場的人(含前輩、品管、背景人物)一律安全帽、護目鏡、手套、安全鞋,胸前別氧氣偵測器(依業主規定);不穿無塵衣(與 L001 相同)。
- **聲明**:故事、工廠、人物與數字皆為虛構。片中的壓力、目標濃度、吹淨氣的雜質都是為了好算取的整數,不是任何規範的數值。算出來的次數是「理想情況下至少要做幾次」,而且偏樂觀;實際的目標、次數與程序,依業主規範或氣體供應商的規定。危害性製程氣體(毒性、可燃、腐蝕等)的吹淨另有程序,本片不涵蓋。

## 第三章 錶上的零,不是空的(2:33–3:48)【教學 + 典型錯誤】

| 旁白或台詞 | 畫面 |
|---|---|
| **陳師傅**:昨天,你們加到幾?洩到幾? | 白板空出一塊 |
| **阿樹**:錶上加到四,洩到零。 | 阿樹在白板寫:高 4、低 0 |
| **陳師傅**:比值呢? | 陳師傅把筆遞給阿樹 |
| **阿樹**:零除以四……等於零!師傅,一次就全部乾淨了! | 阿樹寫「0 ÷ 4 = 0」,畫兩個驚嘆號,得意轉身 |
| **陳師傅**:一次就乾淨,那你們為什麼做三次?品管又為什麼說沒過? | 陳師傅沒抬頭,吹茶 |
| **阿樹**:呃…… | 阿樹的笑容僵住,白板上的「0」開始發抖 |
| **陳師傅**:洩到零的時候,管子裡是真空嗎? | 陳師傅畫一段管子,錶指在 0 |
| **阿樹**:不是……裡面還有滿滿一管子的氣,跟外面一樣。 | 管內畫滿分子,跟管外一樣密 |
| **陳師傅**:對。錶上的零,是跟外面的大氣一樣,大約一 bar。錶量的,是比大氣多出多少,叫錶壓。 | 【圖 4 錶壓與絕對壓力柱】下段「大氣壓 約 1 bar」,上段「錶壓」,整根「絕對壓力」。白板寫:絕對壓力 = 錶壓 + 約 1 bar |
| **陳師傅**:管子裡真正有多少氣,要看絕對壓力。杯底那一口,就是這個一。錶上看不到它,它還在。 | 第二章杯子圖的杯底那一口,標上「1 bar」 |
| **旁白**:洩到零,絕對壓力是一;加到四,絕對壓力是五。比值是一除以五。每做一次,剩五分之一,也就是去掉八成。 | 白板:「0 ÷ 4 = 0」劃掉 → (0 + 1) ÷ (4 + 1) = **1 ÷ 5**;小字「每次去掉 80%」 |
| **陳師傅**:用錶壓去算,分子分母都少了那個一,比值一定變小,算出來一定太樂觀。洩到零的時候最明顯,直接變成零。 | 白板旁紅框:錶壓代入 → 比值太小 → 偏樂觀(一定) |
| **旁白**:不只洩到零才會錯。如果洩到一 bar 錶壓、充到四,錶壓算是四分之一;換成絕對壓力,是二除以五,五分之二。每次剩下的,多了六成。 | 白板另一角:錶壓 1 ÷ 4 = 0.25 ✕;絕對 (1 + 1) ÷ (4 + 1) = 2 ÷ 5 = 0.4 ✔;小字「0.4 ÷ 0.25 = 1.6」 |
| **旁白**:另外,大氣壓我們當成一 bar,其實大約是一點零一三。這也讓結果偏樂觀一點點。影響很小,但方向要知道。 | 黃色便利貼貼在白板角落:「大氣壓 ≈ 1.013 bar,當成 1 → 偏樂觀一點點」(之後各章都留在白板上) |

## 第四章 三次,還剩多少?(3:48–5:30)【教學:計算】

| 旁白或台詞 | 畫面 |
|---|---|
| **陳師傅**:現在算你們那三次。先當最髒的情況:整條管子都是空氣。空氣裡的氧,大約百分之二十一。 | 白板:起點 = 整條都是空氣,氧 ≈ 21%(旁註「最髒的起點」) |
| **旁白**:百分之二十一,就是二十一萬 ppm。ppm 是百萬分之一。 | 白板:21% = 210,000 ppm;小字 1% = 10,000 ppm |
| **阿樹**:每次剩五分之一。第一次,四萬兩千。第二次,八千四百。第三次,一千六百八十。 | 【圖 5 階梯圖】三根柱子依序縮短,標 42,000/8,400/1,680 ppm |
| **陳師傅**:三次,而且一切都理想,還剩一千六百八十 ppm。 | 「1,680」被紅筆圈起來 |
| **旁白**:三次,是五乘五乘五,一百二十五分之一。氧從百分之二十一,降到百分之零點一六八。品管說沒過,一點都不奇怪。 | 白板:5 × 5 × 5 = 125;210,000 ÷ 125 = 1,680 ppm = 0.168% |
| **陳師傅**:那要做幾次?先要有目標。 | 陳師傅在階梯圖上畫一條水平線 |
| **旁白**:本集的目標,訂在氧十 ppm 以下。這是為了好算虛構的數字,不是任何規範。你們的目標,看業主的規範。 | 水平線標「目標 10 ppm(示範)」。字卡:「目標 → 看業主規範」 |
| **阿樹**:可是三次,已經去掉百分之九十九點二了耶。 | 白板:1 − 1/125 = 99.2% |
| **陳師傅**:聽起來很多。剩下的一千六百八十,還是目標的一百六十八倍。 | 白板:1,680 ÷ 10 = 168 倍。「99.2%」字樣縮小,「168 倍」放大 |
| **阿樹**:第四次,三百三十六。第五次,六十七點二。第六次,十三點四四……還沒到。第七次,二點六八八。七次! | 階梯圖繼續:336/67.2/13.44(仍在線上方,紅色)/2.688(在線下方,綠色) |

## 重點整理(片尾卡)

**一行公式(含使用條件)**

> Cₙ = C₀ ×(P低 ÷ P高)ⁿ;要到目標 C目標:n ≥ log(C₀ ÷ C目標)÷ log(P高 ÷ P低),無條件進位。
> 使用條件:P低、P高 一律用**絕對壓力**(錶壓 + 約 1 bar);假設每次完全混合、沒有盲管與長支管、沒有漏、吹淨氣本身比目標乾淨、溫度不變;只適用氣相、會均勻混合的雜質(不適用吸附在管壁的水氣);結果是**理想情況下至少要做的次數,偏樂觀**,合不合格以量測為準;目標、次數、程序依業主規範或氣體供應商;不適用危害性製程氣體的吹淨程序。

**本集範例**:錶壓 4 → 0,比值 (0 + 1) ÷ (4 + 1) = 1/5;起點 210,000 ppm;三次後 210,000 ÷ 125 = **1,680 ppm**;到示範目標 10 ppm:log(21,000) ÷ log(5) = 4.322 ÷ 0.699 ≈ 6.18 → **7 次**(七次後 2.688 ppm)。

**五個重點**

1. 每做一次充壓洩壓,管子裡的氣被稀釋成「洩完的絕對壓力 ÷ 充飽的絕對壓力」;做 n 次,就是這個比值的 n 次方。
2. 比值一定用絕對壓力(錶壓 + 約 1 bar)。用錶壓會算出「一次就乾淨」這種錯的答案,而且永遠偏樂觀。
3. 次數由比值和目標一起決定:同樣從空氣到 10 ppm(示範),比值 1/2 要 15 次、1/5 要 7 次、1/10 要 5 次。「三次」只有配上對的比值和目標才對;壓力不能超過這條線允許的值。
4. 公式大多偏樂觀:盲管與長支管、同一頭進出造成的混合不均、漏、管壁上的水氣,都會讓實際比算的髒;吹淨氣本身的雜質是做不下去的底線。算出來的是「至少幾次」,合不合格要量。
5. 目標、次數、程序看業主規範或氣體供應商;排氣接到指定的安全地方,氮氣會造成缺氧而且察覺不到;危害性製程氣體另有程序。

**驗算程式(Python 3,可直接重跑;改了壓力或目標時,用它重算全片數字)**

```python
from fractions import Fraction as F
import math
C0, T = 210000, 10                       # ppm:起點(空氣,氧 21%)、示範目標
def run(p_low_abs, p_high_abs, c0=C0, floor=0):
    r = F(p_low_abs) / F(p_high_abs)
    c, n, rows = F(c0), 0, [(0, float(c0))]
    while c > T:
        c = floor + (c - floor) * r
        n += 1
        rows.append((n, float(c)))
    return r, n, rows
r, n, rows = run(0 + 1, 4 + 1)           # 錶壓 0 與 4,各加 1 bar
print(r, n, rows)                        # 1/5,7 次,表 A
for lo, hi in [(1, 2), (1, 5), (1, 10), (F(1, 10), 5)]:
    r, n, rows = run(lo, hi)
    print(r, n, rows[-1][1], rows[-2][1], float(C0 * r**3))   # 表 C
print(math.log10(21000) / math.log10(5))                        # 表 B:6.18…
atm = F(101325, 100000)                                          # 大氣壓 1.01325 bar
re = atm / (4 + atm)
print(float(re), [round(float(C0 * re**k), 3) for k in (3, 6, 7)])   # 表 E
print([round(float(1 + (C0 - 1) * F(1, 5)**k), 3) for k in (3, 6, 7, 8)])  # 吹淨氣含氧 1 ppm
```

撰寫時另用一支獨立寫的 awk 程式(浮點數、封閉解 Cₙ = C₀ × rⁿ 與 n = ⌈ln(C₀ ÷ C目標) ÷ ln(1 ÷ r)⌉)重算一次,全部數字與上面一致。
