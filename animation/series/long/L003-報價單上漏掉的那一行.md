# L003 報價單上漏掉的那一行

| 欄位 | 內容 |
|---|---|
| 主標題 | 報價單上漏掉的那一行：得標那天，就是賠錢的開始 |
| 測試標題 A | 菜鳥第一次報價就得標，開工前會勘那天利潤歸零 |
| 測試標題 B | 師傅抬頭看了一眼天花板，二十二萬的案子倒貼十八萬 |
| 測試標題 C | 工程報價最常漏的九行，漏一行賠一筆 |
| 給觀眾的一句承諾 | 看完這十分鐘，你會有一套「六層成本表＋九個漏項＋假設與不含」的方法，送出報價單之前自己抓得出漏掉的那一行。 |
| 目標觀眾 | 剛開始接觸報價的工程師、工地主任、小型工程行與統包商的業務和估算人員；想看懂廠商報價單的業主窗口。 |
| 類型 | 故事 + 計算拆解 |
| 預估長度 | 約 10 分鐘（旁白與台詞約 2,766 字（只計中文字與數字，不含標點），語速約每分鐘 275 至 280 字） |
| 固定角色 | 阿樹（菜鳥工程師，認真、容易臉紅）、陳師傅（公司自己的資深領班，負責帶配合的工班；冷靜、冷面笑匠、用問句教人） |
| 設定 | 虛構的小型配管工程行（乙方），向客戶（甲方）報一條廠房壓縮空氣管：兩吋不鏽鋼管，全程氬焊對接。工資發給配合的工班（丙方）。Q 版卡通風格。 |

> 全片為虛構故事，不使用任何真實公司、業主、人名。所有金額都是為了方便心算而編的整數，不是市場行情。這句話在片中會出現三次（第 1 章、第 4 章、第 6 章）並全程以角標顯示。

## 第 1 章　一個晚上的報價單（0:15–1:10）【故事】

| 旁白或台詞 | 畫面 |
|---|---|
| 旁白：阿樹在一家小配管工程行上班，今年第二年。老闆丟給他一張圖：客戶的廠房要拉一條兩吋的不鏽鋼管送壓縮空氣，全部用焊的。 | 小辦公室。一張平面圖滑到阿樹桌上，圖上一條藍色管線繞過幾台機器，圖角標註「2" 不鏽鋼管・氬焊」。 |
| 阿樹：報價喔？我來！一個晚上就好。 | 阿樹拍胸脯，眼睛發亮。牆上時鐘快轉到半夜。 |
| 旁白：管子，圖上量起來九十米，一米一千，九萬。彎頭、三通、閥件，三萬。材料十二萬。 | 畫面右側跳出【表 1】阿樹版報價單，第一行「材料 120,000」亮起。 |
| 旁白：工資，他問了配合的工班班長。兩個人做十天，一人一天四千，八萬。 | 阿樹滑手機，LINE 對話框裡班長回了一串訊息，阿樹只看到中間的金額就把手機蓋上。【表 1】第二行「工資 80,000」亮起。 |
| 旁白：加起來二十萬。再加一成的管理費跟利潤，兩萬。未稅二十二萬，含稅二十三萬一千。 | 【表 1】逐行加總到底：200,000 → +20,000 → 220,000 → 稅 11,000 → 「含稅 231,000」放大。 |
| 旁白：先講清楚，這一集的數字都是為了好算才編的整數，不是行情，請不要拿去報價。 | 全螢幕字卡：「金額皆為示意整數，非市場行情」。之後縮成右上角角標，全片保留。 |
| 阿樹：材料、工資、利潤、稅，都有了。完美。 | 阿樹伸懶腰，按下寄出。 |
| 甲方承辦：三家裡面你們回最快，價錢也最漂亮。就給你們做。 | 甲方辦公室。承辦把三份報價單攤在桌上，阿樹那份只有一頁；另外兩份最後都多一頁寫得密密麻麻的備註。 |
| 旁白：價錢最漂亮。這句話，阿樹當時聽起來是稱讚。 | 「價錢也最漂亮」幾個字在阿樹頭上繞圈發光，阿樹頭上冒出小皇冠。 |

## 第 2 章　天花板上的那一行（1:10–2:05）【故事】

| 旁白或台詞 | 畫面 |
|---|---|
| 旁白：開工前會勘那天，陳師傅走進廠房，沒有看圖，先抬頭。 | 廠房內景，挑高，機台排成一列。陳師傅、阿樹、甲方承辦都戴安全帽、穿反光背心。陳師傅仰頭。 |
| 陳師傅：管子走哪裡？ | 陳師傅對嘴，眼睛沒有離開天花板。 |
| 阿樹：上面啊，貼著天花板走。 | 阿樹跟著抬頭，手指往上比。 |
| 陳師傅：多高？ | 鏡頭由地面慢慢往上搖。 |
| 阿樹：……六米。 | 畫面出現一支尺規動畫，從地面拉到管線位置，標示「6 m」。阿樹的小皇冠歪掉。 |
| 陳師傅：六米。那你的高空車，算在報價單的哪一行？ | 陳師傅終於轉頭看阿樹，面無表情。 |
| 旁白：阿樹把報價單翻過來，又翻過去。沒有那一行。 | 阿樹狂翻紙，冒汗。【表 1】在材料和工資中間裂開一條空白行，閃紅光。 |
| 阿樹：我想說……跟廠裡借一把梯子就好。 | 阿樹小小聲，手指比出一把很小的梯子。 |
| 陳師傅：六米的梯子。你爬，我不爬。 | 陳師傅雙手抱胸。示意畫面：一把梯子立在牆邊，連一半高度都不到，上面蓋一個大紅叉。不畫任何人爬上去。 |
| 旁白：這種高度，不是扛一把梯子就能上去的，要用施工架或高空作業車。一台車租十天，一天兩千五，兩萬五。 | 【圖 A】高度示意：6 m 管線位置、梯子打叉、施工架與高空作業車打勾。旁邊跳出「10 天 × 2,500 = 25,000」。 |
| 旁白：他以為會賺的那兩萬，當場變成負五千。 | 利潤格「+20,000」的數字往下掉，穿過零，停在「−5,000」。小皇冠掉到地上。 |
| 旁白：車也不會自己走過來。板車進場、退場各一趟，一趟四千五，比租一天還貴。車停在現場沒在用的那幾天，租金照算。 | 一台板車載著高空車開進廠區，跳出「2 趟 × 4,500 = 9,000」，利潤格再掉到「−14,000」。月曆上高空車停著不動的日子，計費表照樣跳。 |
| 陳師傅：不要急著哭。這還只是第一行。 | 陳師傅拍拍阿樹肩膀。阿樹眼眶含淚定格。 |
| 旁白：師傅沒有說錯。那天一路走下去，後面又排了好幾行。材料只能卸在大門口。新管要接上舊的主管，得先停氣。工人進廠之前，要先上一整天的課。 | 會勘路線三格：大門口的卸貨區離施工點很遠；陳師傅指著天花板上既有的主管與一顆關斷閥；警衛室牆上貼著「入廠安全訓練」公告。每一格跳出一個「？元」。 |

## 第 3 章　成本是一棟六層樓（2:05–3:25）【教學】

| 旁白或台詞 | 畫面 |
|---|---|
| 旁白：回到公司，師傅沒有罵他，只在白板上畫了一棟六層樓的房子。 | 工務所白板。陳師傅用馬克筆畫出六格疊起來的樓房外框。 |
| 陳師傅：成本是一層一層蓋上去的。你蓋了幾層？ | 陳師傅把筆遞給阿樹。 |
| 阿樹：材料、工資……利潤、稅。四層。 | 阿樹填上四格，中間兩格空著。 |
| 陳師傅：中間空兩層，房子當然會塌。 | 樓房從中間塌陷的小動畫，阿樹縮脖子。 |
| 旁白：第一層，材料。管子、管件、閥，還有吊架。第二層，工資。誰來做，做幾天。 | 【圖 B】六層樓圖，由下往上一層一層亮起，每層旁邊跳出小圖示。 |
| 旁白：第三層，機具與耗材。高空車、焊機、氬氣。 | 【圖 B】第三層亮起：高空車、氬焊機、氣瓶圖示。 |
| 旁白：第四層，間接費用。搬運、保護、測試、文件、現場管理、保險。這些東西不會留在客戶的廠裡，可是每一樣都要花錢。 | 【圖 B】第四層亮起，六個小圖示排成一列。 |
| 旁白：第五層，管理費與利潤。第六層，稅。新手最容易整層不見的，是第四層。 | 【圖 B】最上面兩層亮起，整棟樓完成；第四層變成半透明虛線，閃爍。 |
| 旁白：要注意，這六層是你自己算成本用的。給客戶的那一張，照客戶的格式寫，行數可以少。但是裡面這六層，一定要算過。 | 左右對比：左邊標「內部成本表」，六層樓；右邊標「給客戶的報價單」，只有三四行。一個箭頭從左邊流到右邊，六層的錢一毛不少地裝進右邊的幾行。 |
| 旁白：公共工程的標單，常把安全衛生、品管各自拉成一行。民間的報價單常常沒有。沒有那一行，不代表不用花那個錢。 | 一份很長的公共工程標單和一份很短的民間報價單並排，短的那份底下有錢從破洞漏出去。 |
| 陳師傅：還有，管理費跟利潤是兩件事。管理費是公司開門的成本，利潤才是賺的。寫成同一行，你就會以為那兩萬全部是你的。 | 第五層從中間切成兩半，左半寫「管理費」，右半寫「利潤」。阿樹恍然大悟臉。 |
| 阿樹：可是師傅，那一成我有算啊。 | 阿樹指著自己報價單上的「20,000」。 |
| 陳師傅：一成是乘在誰上面？底下少算，上面那一成也跟著變少。 | 【圖 B】下面四層縮水，最上面兩層跟著變窄。 |

## 第 4 章　從圖面量出數量（3:25–4:35）【故事＋教學】

| 旁白或台詞 | 畫面 |
|---|---|
| 旁白：隔天，師傅把圖攤在桌上。 | 工務所。圖面攤開，旁邊排著昨天會勘拍的現場照片。 |
| 陳師傅：你的九十米，怎麼量的？ | 陳師傅手指敲圖面。 |
| 阿樹：平面圖上一段一段加起來。四十、三十、二十。 | 平面圖上三段藍線依序標出 40、30、20，合計 90。 |
| 陳師傅：管子只會走平的嗎？用氣點在哪裡？ | 陳師傅把一張機台照片推到阿樹面前。 |
| 旁白：管子在六米高，機台的接點在一米。兩個用氣點，每一個都要往下拉五米。二乘五，十米。平面圖上看不到。 | 【圖 C】平面圖翻轉成立體示意：水平主管在 6 m，兩支下降管從主管上方取出、轉彎後垂直往下到 1 m，以橘色亮起，標示「2 × 5 = 10 m」。 |
| 旁白：而且現場有樑、有風管。繞一下，就多兩顆彎頭、多一米管。所以量完圖，一定要去現場走一趟。 | 【圖 C】立體圖上冒出一支大樑和一條風管擋在管線路徑上，藍色管線繞過去，多出兩顆彎頭閃爍。 |
| 旁白：算數量三個步驟。第一，一段一段量，水平加垂直，九十加十，一百米。第二，數顆的。彎頭、三通、閥，一顆一顆點。多了兩支下降管，管件也要跟著加。 | 【表 2】數量計算表第一列：水平 90 ＋ 垂直 10 ＝ 100 m。第二列：管件閥件逐顆打勾，下降管的彎頭、三通、球閥用橘色補上。 |
| 旁白：第三，算跟著長度走的東西。吊架兩米一組，一百米五十組。轉彎跟下降的地方，還要另外補。 | 【表 2】第三列：100 ÷ 2 ＝ 50 組。【圖 C】轉彎處與下降管上多冒出幾個支撐，標「另補」。 |
| 阿樹：那我買一百米就好了？ | 阿樹舉手發問。 |
| 陳師傅：管子一支六米。你切下來的零頭，接得回去嗎？ | 動畫：一支 6 m 管被切成幾段，剩下一小截掉進廢料桶。 |
| 旁白：所以要加損耗。這裡示意抓一成，一百一十米。管子是整支買的，一支六米，要叫十九支。損耗抓多少沒有標準答案，但是不能是零。 | 【表 2】第四列：100 × 1.1 ＝ 110 m；第五列：110 ÷ 6 ＝ 18.3 → 19 支（114 m）。角標閃一下：「損耗 10% 為示意」。 |
| 旁白：對客戶，數量還是寫裝上去的一百米。損耗，攤進每一米的單價裡。 | 【表 2】最後一列：對外數量 100 m；買料 19 支的錢除以 100 m，變成每米單價。 |
| 陳師傅：損耗抓零的人，最後都是自己跑材料行。 | 想像畫面：傍晚，材料行鐵門正要拉下來，阿樹氣喘吁吁站在櫃台前比「一支」。 |

## 第 5 章　最常漏掉的九行（4:35–6:00）【故事＋教學】

| 旁白或台詞 | 畫面 |
|---|---|
| 旁白：第三天，工班班長傳了一則訊息來。 | 阿樹手機震動，螢幕跳出 LINE 通知「班長」。 |
| 丙方班長：阿樹，我上次傳給你的是純工資喔。高空車、垃圾清運、進廠上課那一天，都不含。 | 分割畫面，班長在貨車旁邊按著手機傳語音。 |
| 阿樹：蛤？你沒有講啊！ | 阿樹跳起來。 |
| 丙方班長：你往上滑，我有打。 | 阿樹把 LINE 對話往上滑，停在當初那則報價訊息，最後一行：「以上純工資，不含高空車、清運、入廠訓練」。阿樹臉紅到耳朵。 |
| 旁白：班長沒有騙他。是阿樹只看了金額，沒有看最後那一行。 | 那則訊息裡的金額很大很亮，最後一行小字被阿樹的大拇指壓住。 |
| 陳師傅：記起來。丙方寫的「不含」，就是你要「含」的。 | 【圖 D】三方關係圖：甲方、乙方、丙方三個方塊，丙方的「不含」箭頭彎回乙方，變成乙方的「要含」。 |
| 旁白：師傅從口袋掏出一張摺了很多次的紙。上面是他二十年來漏過的每一行。 | 一張泛黃、摺痕很深的紙攤開，手寫字密密麻麻。 |
| 旁白：一，高空作業車或施工架，連進退場的運費。二，搬運與吊裝，材料怎麼從大門口到天花板。三，保護、清潔與廢棄物清運，機台要蓋，地板要還原，垃圾要載走。 | 【表 3】九個漏項清單，逐項彈出配圖示：高空車、推車與吊鉤、防塵布與太空包。 |
| 旁白：四，測試與吹洗，保壓要時間，也要錶。五，與既有系統銜接及停氣，哪一天停、停多久，是客戶決定的。六，文件與送審，施工計畫、竣工圖，都是人一張一張畫出來的。 | 【表 3】繼續：壓力錶、舊主管上的關斷閥與「停氣」牌、一疊文件。 |
| 阿樹：文件也要算錢喔？ | 阿樹一臉不可置信。 |
| 陳師傅：你昨天施工計畫畫到幾點？ | 陳師傅頭也不抬。 |
| 阿樹：……十一點。 | 回想畫面：深夜，阿樹趴在電腦前，旁邊一碗泡麵。 |
| 陳師傅：那就是錢。 | 泡麵上方跳出一個錢幣符號，飛走。 |
| 旁白：七，入廠訓練與等待工時，人到了不能動工，薪水照算。八，現場負責人、監火與地面監視。有動火，就要有人顧火；車在上面，下面就要有人看著。這些人站在現場的每一天，都是錢。 | 【表 3】繼續：上課的工人；戴安全帽的監火人員站在滅火器旁；高空車下方圍起警示帶，地面監視人員抬頭看著。 |
| 旁白：九，保固。回來修的那一趟一定是你出，所以要先算進去，還要寫明保多久、保什麼。 | 【表 3】完成：掛著「保固：期限／範圍」牌子的扳手。 |

## 重點整理（結尾卡五個重點）

1. 成本有六層：材料、工資、機具與耗材、間接費用、管理費與利潤、稅。這是自己算成本用的；給客戶的報價單照客戶格式，行數可以少，但六層都要算過。
2. 數量自己從圖面量：水平加垂直、逐顆點數、跟著長度走的吊架另算。對外寫裝上去的淨長，損耗攤進單價；買料要換成整支。
3. 圖上沒畫的最容易漏：人怎麼上去、東西怎麼進去、垃圾怎麼出來、舊管怎麼接，還有測試、文件、訓練、等待、現場人力、保固。
4. 丙方寫的「不含」，就是乙方要「含」的。
5. 一定會發生的只能算進去；甲方可提供的寫假設；條件變了才發生的才寫不含。再加上追加減單價與有效期限，才是日後談追加的依據，實際仍以合約為準。

### 一、PM 暫定事項（審查彙整第四節，Rob 可以直接推翻）

1. **【PM 暫定 A】九個漏項的清單**：改為高空作業車或施工架；搬運與吊裝；保護、清潔與廢棄物清運（三項合併）；測試與吹洗；與既有系統銜接及停氣；文件與送審；入廠訓練與等待工時；現場負責人、監火與地面監視；保固。保固改成「一定是乙方出，所以要先算進去，並寫明期限與範圍」。夜間或假日施工移到第 7 章，當作「不含」的示範。這九項與順序是否貼近實務？
2. **【PM 暫定 B】高空作業車的數字**：租金 10 天 × 2,500、進退場 2 趟 × 4,500（一趟比一天租金貴）、耗材 3,000，並加一句「車停在現場沒在用的日子，租金照算」。比例與說法是否合理？
3. **【PM 暫定 C】吊架**：50 組 × 400（含固定件），並加一句「轉彎跟下降的地方還要另外補」。本例沒有把另補的數量算進金額。
4. **【PM 暫定 D】管理費與利潤**：拆成管理費 6%、利潤 4% 兩行，並說明比例每家公司不同。保固在內部成本表獨立一行（示意 10,000）。合計一成是否仍偏薄、要不要換別的示意比例？
5. **【PM 暫定 E】內部成本表與對外報價單**：片中明講六層是乙方自己算成本用的，給客戶的報價單照客戶格式、行數可以少。附錄 A 另做了一張四行的對外報價單示意（每行＝內部成本 × 1.1）。對外要列幾行、間接費用要獨立列還是攤進每米單價，請依實務習慣裁決。

### 二、這次修訂新增、需要確認的事項

6. **管材規格**：定為「兩吋不鏽鋼管，全程氬焊對接」，好讓動火許可與監火前後一致。壓縮空氣管用這個規格與接法是否合理？一支六米、吊架兩米一組、耗材（焊材、氬氣、切割片）的說法是否成立？
7. **下降管**：依領班意見改成兩個用氣點、各由六米降到一米（2 × 5 m），圖 C 註明支管由主管上方取出。領班自評信心為中，請確認畫法與高度。
8. **現場負責人、監火與地面監視**：片中以「十個人天 × 4,000」示意，沒有說幾個人。監火、地面監視能不能由現場負責人兼任、實際要幾個人，請依廠規與現行規定確認；片中不下結論。
9. **等待工時條款**：附錄的示範寫「單日累計超過兩小時起算、每人每日 5,000、當日由甲方現場窗口簽認」。門檻與寫法甲方實務上會不會接受？
10. **保固一年、限施工與材料瑕疵**：期限與範圍是示意，是否貼近常見約定。
11. **追加減單價**：配管每米 2,750（含工料）、點工每人每日 5,000，僅為示意。
12. **夜間追加那場戲**：改成「補一張夜間差額的追加報價，等訂單變更下來再排班」。現場是否真的這樣走。
13. **工安畫面規定**：製作備註裡寫的安全帽、全身式安全帶掛鉤、下方管制區、監火人員，是否符合現場與現行規定，有沒有漏掉該畫的防護。
14. **審查引用的法條未經查證**：業主角色憑記憶引用民法與營業稅法的條號（承攬報酬未約定時如何認定、營業稅內含或外加）。片中與說明欄都不提條號，只講「實際以合約約定為準」。如要引用，請先查現行條文。
15. **營業稅 5%**：範例沿用原稿的 5%，請確認現行稅率與「未稅加稅」的列法。

### 三、原有待確認事項（仍適用）

16. **用詞**：片中用「高空作業車」，口語用「高空車」；法規用語可能是「高空工作車」。現場習慣哪一個？標題與檢核表要不要統一。
17. **高處作業的說法**：旁白已改成不提公尺數的一般說法（「這種高度，不是扛一把梯子就能上去的，要用施工架或高空作業車」）。高處作業的高度門檻、合梯在什麼條件下可以用、高空工作車的操作資格，都需要以現行條文與廠規確認後，再決定要不要講得更具體。
18. **六層的分法**：公共工程常把職業安全衛生費、品管費、環保費各自獨立一行。民間配管報價是否習慣這樣分，還是「工帶料」合成單價比較常見。
19. **損耗一成**：只是示意。不同管材、管徑的習慣範圍大概是多少，片中講「沒有標準答案，但是不能是零」夠不夠。
20. **比例關係**：材料 17 萬、工資 8.8 萬、間接費用 10.5 萬、師傅一天四千。雖然是示意整數，比例會不會讓內行人出戲；重算後成本剛好是原本的兩倍，會不會太誇張。
21. **丙方只報純工資、不含高空車與清運**：工班用 LINE 這樣報是否常見，「點工」「純工資」「連工帶料」的用法有沒有說錯。
22. **入廠訓練一次一天**：這樣的假設甲方實務上會不會接受。
23. **「實作實算」**：已依審查改為「實作實算」。總價承攬的案子寫這句、以及「不含」條款，是否有實際效力，需要另外查證。
24. **第 7 章阿樹回覆甲方的那段話**：語氣會不會太硬。
25. **是否有任何情節會讓人聯想到特定公司或案子**。
