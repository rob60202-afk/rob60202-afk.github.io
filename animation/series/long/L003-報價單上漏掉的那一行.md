# L003 報價單上漏掉的那一行

| 欄位 | 內容 |
|---|---|
| 主標題 | 報價單上漏掉的那一行：得標那天，就是賠錢的開始 |
| 測試標題 A | 菜鳥第一次報價就得標，進場第一天利潤歸零 |
| 測試標題 B | 師傅抬頭看了一眼天花板，二十二萬的案子倒貼八萬 |
| 測試標題 C | 工程報價最常漏的九行，漏一行賠一筆 |
| 給觀眾的一句承諾 | 看完這十分鐘，你會有一套「六層架構＋九個漏項＋假設與不含」的方法，送出報價單之前自己抓得出漏掉的那一行。 |
| 目標觀眾 | 剛開始接觸報價的工程師、工地主任、小型工程行與統包商的業務和估算人員；想看懂廠商報價單的業主窗口。 |
| 類型 | 故事 + 計算拆解 |
| 預估長度 | 約 10 分鐘（旁白與台詞約 2,661 字（只計中文字與數字，不含標點），語速約每分鐘 270 至 280 字） |
| 固定角色 | 阿樹（菜鳥工程師，認真、容易臉紅）、陳師傅（資深領班，冷靜、冷面笑匠、用問句教人） |
| 設定 | 虛構的小型配管工程行（乙方），向客戶（甲方）報一條廠房壓縮空氣管，工資發給配合的工班（丙方）。Q 版卡通風格。 |

> 全片為虛構故事，不使用任何真實公司、業主、人名。所有金額都是為了方便心算而編的整數，不是市場行情。這句話在片中會出現三次（第 1 章、第 4 章、第 6 章）並全程以角標顯示。

## 第 1 章　一個晚上的報價單（0:15–1:20）【故事】

| 旁白或台詞 | 畫面 |
|---|---|
| 旁白：阿樹在一家小小的配管工程行上班，今年第二年。這天老闆丟給他一張圖，客戶的廠房要拉一條壓縮空氣管。 | 小辦公室。一張平面圖滑到阿樹桌上，圖上一條藍色管線繞過幾台機器。 |
| 阿樹：報價喔？我來！一個晚上就好。 | 阿樹拍胸脯，眼睛發亮。牆上時鐘快轉到半夜。 |
| 旁白：他算得很認真。管子，圖上量起來九十米，一米算一千，九萬。彎頭、三通、閥件，三萬。材料一共十二萬。 | 畫面右側跳出【表 1】阿樹版報價單，第一行「材料 120,000」亮起。 |
| 旁白：工資，他打電話問了配合的工班班長。兩個人做十天，一個人一天四千，八萬。 | 分割畫面：阿樹講電話，另一頭是戴帽子的丙方班長。【表 1】第二行「工資 80,000」亮起。 |
| 旁白：十二萬加八萬，二十萬。再加一成的管理費跟利潤，兩萬。未稅二十二萬，加百分之五營業稅，含稅二十三萬一千。 | 【表 1】逐行加總到底，最後一格「含稅 231,000」放大。 |
| 旁白：先講清楚，這一集所有的數字，都是為了好算才編的整數，不是行情，請不要拿去報價。 | 全螢幕字卡：「金額皆為示意整數，非市場行情」。之後縮成右上角角標，全片保留。 |
| 旁白：他還上網找了一份報價單範本，把數字填進去，排版排得漂漂亮亮。 | 螢幕上一份格式精美的報價單，阿樹調整框線粗細，滿意點頭。 |
| 阿樹：材料、工資、利潤、稅，都有了。完美。 | 阿樹伸懶腰，按下寄出。 |
| 甲方承辦：三家裡面你們回最快，價錢也最漂亮。就給你們做。 | 甲方辦公室。承辦把三份報價單攤在桌上，阿樹那份明顯最薄。 |
| 旁白：價錢最漂亮。這句話，阿樹當時聽起來是稱讚。 | 「價錢也最漂亮」幾個字在阿樹頭上繞圈發光。畫面角落，另外兩份報價單比較厚，隱約看得到很多行。 |
| 旁白：客戶很快就簽了。阿樹覺得，自己出師了。 | 隔天，和甲方承辦握手。阿樹頭上冒出小皇冠。 |

## 第 2 章　天花板上的那一行（1:20–2:15）【故事】

| 旁白或台詞 | 畫面 |
|---|---|
| 旁白：進場第一天，陳師傅走進廠房，沒有看圖，先抬頭。 | 廠房內景，挑高，機台排成一列。陳師傅雙手插口袋仰頭。 |
| 陳師傅：管子走哪裡？ | 陳師傅對嘴，眼睛沒有離開天花板。 |
| 阿樹：上面啊，貼著天花板走。 | 阿樹跟著抬頭，手指往上比。 |
| 陳師傅：多高？ | 鏡頭由地面慢慢往上搖。 |
| 阿樹：……六米。 | 畫面出現一支尺規動畫，從地面拉到管線位置，標示「6 m」。阿樹的小皇冠歪掉。 |
| 陳師傅：六米。那你的高空車，算在報價單的哪一行？ | 陳師傅終於轉頭看阿樹，面無表情。 |
| 旁白：阿樹把報價單翻過來，又翻過去。沒有那一行。 | 阿樹狂翻紙，冒汗。【表 1】在材料和工資中間裂開一條空白行，閃紅光。 |
| 阿樹：我想說……跟廠裡借一把梯子就好。 | 阿樹小小聲，手指比出一把很小的梯子。 |
| 陳師傅：六米的梯子。你爬，我不爬。 | 陳師傅雙手抱胸。想像畫面：阿樹抱著一支六米管在超長梯子頂端搖晃。 |
| 旁白：兩公尺以上的高處作業，不能扛一把梯子就上去，要有施工架或高空作業車。一台車租十天，一天三千，三萬。 | 【圖 A】高度示意：2 m 畫一條紅線，紅線以上標「施工架／高空作業車」。旁邊跳出「10 天 × 3,000 = 30,000」。 |
| 旁白：而且車不會自己走過來。進場、退場各一趟的運費，他也沒有算。 | 一台板車載著高空車開進廠區，計費表跳動，再跳出「運費 ×2」。 |
| 旁白：他以為會賺的那兩萬，當場變成負一萬。 | 利潤格「+20,000」的數字往下掉，穿過零，停在「−10,000」。小皇冠掉到地上。 |
| 陳師傅：不要急著哭。這還只是第一行。 | 陳師傅拍拍阿樹肩膀。阿樹眼眶含淚定格。 |
| 旁白：師傅沒有說錯。接下來三天，那一行的後面又排了好幾行。材料送到大門口，沒有人搬。管子不夠長，要補。工人到了，卻要先上一整天的課。 | 快速蒙太奇三格：一捆管子孤零零放在大門口；阿樹量管子發現差一截；兩個工人坐在教室裡看安全影片，牆上時鐘在走。每一格跳出一個「？元」。 |

## 第 3 章　報價單是一棟六層樓（2:15–3:35）【教學】

| 旁白或台詞 | 畫面 |
|---|---|
| 旁白：那天收工，師傅沒有罵他，只在白板上畫了一棟六層樓的房子。 | 工務所白板。陳師傅用馬克筆畫出六格疊起來的樓房外框。 |
| 陳師傅：報價單是一層一層蓋上去的。你蓋了幾層？ | 陳師傅把筆遞給阿樹。 |
| 阿樹：材料、工資……利潤、稅。四層。 | 阿樹填上四格，中間兩格空著。 |
| 陳師傅：中間空兩層，房子當然會塌。 | 樓房從中間塌陷的小動畫，阿樹縮脖子。 |
| 旁白：第一層，材料。管子、管件、閥，還有吊架這些五金另料。第二層，工資。誰來做，做幾天。 | 【圖 B】六層樓圖，由下往上一層一層亮起，每層旁邊跳出小圖示。 |
| 旁白：第三層，機具與耗材。高空車、焊機、切割片。 | 【圖 B】第三層亮起：高空車、焊機圖示。 |
| 旁白：第四層，間接費用。搬運、保護、測試、文件、清運、保險。這些東西不會留在客戶的廠裡，可是每一樣都要花錢。 | 【圖 B】第四層亮起，六個小圖示排成一列。 |
| 旁白：第五層，管理費與利潤。第六層，稅。 | 【圖 B】最上面兩層亮起，整棟樓完成。 |
| 旁白：前三層是看得到、摸得到的東西跟人，新手通常不會全忘。最容易整層不見的，是第四層。 | 【圖 B】第四層變成半透明虛線，閃爍。 |
| 陳師傅：公家的案子，會把安全衛生、品管這些各自拉成一行。民間的報價單常常沒有那一行。沒有那一行，不代表不用花那個錢。 | 左右對比：左邊一份很長的公共工程標單，右邊一份很短的民間報價單，短的那份底下有錢從破洞漏出去。 |
| 陳師傅：還有，管理費跟利潤是兩件事。管理費是公司開門的成本，利潤才是賺的。你把它們寫成同一行，就會以為那兩萬全部是你的。 | 第五層從中間切成兩半，左半寫「管理費」，右半寫「利潤」。阿樹恍然大悟臉。 |
| 阿樹：可是師傅，那一成我有算啊。 | 阿樹指著自己報價單上的「20,000」。 |
| 陳師傅：一成是乘在誰上面？底下少算十萬，上面那一成也跟著少一萬。 | 【圖 B】下面四層縮水，最上面兩層跟著變窄。 |

## 第 4 章　從圖面量出數量（3:35–4:45）【故事＋教學】

| 旁白或台詞 | 畫面 |
|---|---|
| 旁白：隔天，師傅把圖攤在高空車的平台上。 | 現場。高空車已經進場，圖面攤開用磁鐵壓住。 |
| 陳師傅：你的九十米，怎麼量的？ | 陳師傅手指敲圖面。 |
| 阿樹：平面圖上一段一段加起來。四十、三十、二十。 | 平面圖上三段藍線依序標出 40、30、20，合計 90。 |
| 陳師傅：管子只會走平的嗎？用氣點在哪裡？ | 陳師傅抬下巴指向機台。 |
| 旁白：阿樹抬頭，再低頭。管子在六米高，機台的接點在四米。五個用氣點，每一個都要往下拉兩米。五乘二，十米。平面圖上看不到。 | 【圖 C】平面圖翻轉成立體示意：水平主管在 6 m，五支垂直下降管各 2 m 以橘色亮起，標示「5 × 2 = 10 m」。 |
| 旁白：還有，圖是畫給理想世界看的。現場有樑、有風管、有別人先裝好的管子。繞一下，就是多兩顆彎頭、多一米管。所以量完圖，一定要去現場走一趟。 | 【圖 C】立體圖上冒出一支大樑和一條風管擋在管線路徑上，藍色管線繞過去，多出兩顆彎頭閃爍。阿樹拿著圖在現場邊走邊抬頭。 |
| 旁白：算數量有三個步驟。第一，照系統一段一段量，水平加垂直，九十加十，一百米。 | 【表 2】數量計算表第一列：水平 90 ＋ 垂直 10 ＝ 100 m。 |
| 旁白：第二，數顆的。彎頭、三通、閥，一顆一顆點。第三，算跟著長度走的東西。吊架每兩米一組，一百米就是五十組。 | 【表 2】第二列：管件閥件逐顆打勾。第三列：100 ÷ 2 ＝ 50 組。 |
| 阿樹：那我買一百米就好了？ | 阿樹舉手發問。 |
| 陳師傅：管子一支六米。你切下來的零頭，接得回去嗎？ | 動畫：一支 6 m 管被切成幾段，剩下一小截掉進廢料桶。 |
| 旁白：所以要加損耗。這裡示意抓一成，一百米變一百一十米。損耗要抓多少，看材料、看管徑、看現場，沒有標準答案，但是不能是零。 | 【表 2】最後一列：100 × 1.1 ＝ 110 m。角標閃一下：「損耗 10% 為示意」。 |
| 陳師傅：損耗抓零的人，最後都是自己騎車去材料行。 | 想像畫面：阿樹騎機車扛著一支管子，在夕陽下狂奔。 |

## 第 5 章　最常漏掉的九行（4:45–6:10）【故事＋教學】

| 旁白或台詞 | 畫面 |
|---|---|
| 旁白：第三天，工班班長打電話來。 | 阿樹手機響，螢幕顯示「班長」。 |
| 丙方班長：阿樹，我報給你的是純工資喔。高空車、垃圾清運、進廠上課那一天，都不含。 | 分割畫面，班長在貨車旁邊講電話。 |
| 阿樹：蛤？你沒有講啊！ | 阿樹跳起來。 |
| 丙方班長：我報價單最下面有寫。 | 鏡頭推到丙方報價單最底下一行小字：「以上不含……」。阿樹臉紅到耳朵。 |
| 旁白：班長沒有騙他。是阿樹只看了總價，沒有看最下面那一行。 | 丙方報價單的總價數字很大很亮，最底下那行小字被阿樹的大拇指壓住。 |
| 陳師傅：記起來。丙方寫的「不含」，就是你要「含」的。 | 【圖 D】三方關係圖：甲方、乙方、丙方三個方塊，丙方的「不含」箭頭彎回乙方，變成乙方的「要含」。 |
| 旁白：師傅從口袋掏出一張摺了很多次的紙。上面是他二十年來漏過的每一行。 | 一張泛黃、摺痕很深的紙攤開，手寫字密密麻麻。 |
| 旁白：一，高空作業車或施工架，連進場退場的運費。二，搬運與吊裝，貨車只能停在大門口，材料怎麼從那裡到天花板。三，保護與清潔，客戶的機台要蓋，地板要還原。 | 【表 3】九個漏項清單，逐項彈出配圖示：高空車、推車與吊鉤、防塵布與拖把。 |
| 旁白：四，測試與檢驗，保壓要時間，也要錶。五，文件與送審，施工計畫、材料送審、竣工圖，都是人坐在那裡一張一張畫出來的。六，夜間或假日施工，工資不是同一個價。 | 【表 3】繼續：壓力錶、一疊文件、月亮。 |
| 阿樹：文件也要算錢喔？ | 阿樹一臉不可置信。 |
| 陳師傅：你昨天施工計畫畫到幾點？ | 陳師傅頭也不抬。 |
| 阿樹：……十一點。 | 回想畫面：深夜，阿樹趴在電腦前，旁邊一碗泡麵。 |
| 陳師傅：那就是錢。 | 泡麵上方跳出一個錢幣符號，飛走。 |
| 旁白：七，入廠訓練與等待工時，人到了不能動工，一堂課上完一天就過了，薪水照算。八，廢棄物清運。九，保固。一年內回來修的那一趟，車錢工錢誰出？ | 【表 3】完成：上課的工人、太空包、掛著「保固一年」牌子的扳手。 |
| 旁白：這九行不是每個案子都會發生。但是每一行，你都要問過一次，然後決定：算進去，還是寫明不含。 | 【表 3】每一列右邊出現兩個選項框：「算進去」「寫不含」，逐列打勾。 |
| 陳師傅：這九行有一個共同點。圖上，都沒有畫。 | 鏡頭回到平面圖，九個圖示一個一個從圖面外飛進來，圖上原本什麼都沒有。 |

## 第 6 章　重算一次：前後對照（6:10–7:25）【計算拆解】

| 旁白或台詞 | 畫面 |
|---|---|
| 旁白：師傅陪阿樹把報價單重算一次。六層樓，一層一層來。再提醒一次，數字都是示意的整數。 | 兩人並肩坐在工務所。螢幕上【表 4】重算版報價單，六層架構空白待填。 |
| 旁白：材料。管子一百一十米，十一萬。管件閥件三萬。吊架五十組，一組兩百，一萬。小計十五萬。 | 【表 4】第一層逐行填入：110,000／30,000／10,000，小計 150,000。 |

## 重點整理（結尾卡五個重點）

1. 報價單有六層：材料、工資、機具與耗材、間接費用、管理費與利潤、稅。少一層就會塌。
2. 數量自己從圖面量：水平加垂直、逐顆點數、跟著長度走的吊架另算，最後一定要加損耗。
3. 圖上沒畫的最容易漏：人怎麼上去、東西怎麼進去、垃圾怎麼出來，還有測試、文件、訓練、等待、保固。
4. 丙方寫的「不含」，就是乙方要「含」的。
5. 價錢可以不報，話一定要寫：假設、不含、數量增減的算法、有效期限，是日後談追加的依據。

2. **兩公尺的說法**：旁白說「兩公尺以上的高處作業，不能扛一把梯子就上去，要有施工架或高空作業車」。這是把法規簡化後的講法，請確認不會誤導（例如合梯在什麼條件下可以用、廠區是否有更嚴格的規定）。
3. **六層的分法**：片中分成材料、工資、機具與耗材、間接費用、管理費與利潤、稅。公共工程常見的寫法是把職業安全衛生費、品管費、環保費各自獨立一行，再列管理費及利潤、營業稅。民間配管報價是否習慣這樣分，還是「工帶料」合成單價比較常見。
4. **九個漏項是否貼近實務**：高空作業車或施工架、搬運與吊裝、保護與清潔、測試與檢驗、文件與送審、夜間或假日施工、入廠訓練與等待工時、廢棄物清運、保固。有沒有更常漏、應該換進來的（例如動火許可與監火人員、無塵室規定、開孔與防火填塞、保溫、油漆與標示、圖面套繪、保險、保留款的資金成本）。
5. **損耗一成**：只是示意。實務上不同管材、管徑的習慣範圍大概是多少，片中講「看材料、看管徑、看現場」夠不夠。
6. **管子一支六米**：這個說法對片中的壓縮空氣管是否成立，還是應該改成不講長度。
7. **吊架每兩米一組**：示意間距，是否太離譜。
8. **比例關係**：材料 15 萬、工資 8.8 萬、高空車一天三千、師傅一天四千。雖然是示意整數，比例會不會讓內行人覺得出戲。管理費與利潤合計一成是否合理。
9. **丙方只報純工資、不含高空車與清運**：工班報價這樣寫是否常見，「點工」「純工資」「連工帶料」的用法有沒有說錯。
10. **入廠訓練一次一天、等待工時按點工另計**：這樣的假設與不含條款，甲方實務上會不會接受，寫法要不要調整。
11. **「實做實算」**：寫法是「實做實算」還是「實作實算」，以及總價承攬的案子寫這句是否有實際效果。
12. **保固放在管理費裡**：片中這樣處理，實務上是否有人會獨立列一行或用保固保證金。
13. **第 7 章阿樹回覆甲方的那段話**：語氣會不會太硬，現場真的會這樣講嗎。
14. **法律面**：片中說「假設寫清楚才有依據談追加」。能不能追加還是要看合約（總價承攬、合約優先順序等），是否需要在說明欄加一句「實際以合約約定為準」。
15. **是否有任何情節會讓人聯想到特定公司或案子**。
